# 스마트에디터 ONE 단축키 (Windows) — 자동화용

출처: 사장님 제공 (네이버 스마트에디터 도움말 / m.blog.naver.com/upssuyo/222143750810 참고)
확장(chrome.debugger)이 **좌표 클릭 없이 단축키로** 서식을 넣을 때 사용.

## 서식 (자동화에 직접 쓰는 것 ⭐)
| 기능 | 단축키 | 비고 |
|---|---|---|
| 붙여넣기 | **Ctrl+V** | 본문 입력(서식HTML) ⭐ |
| 굵게 | **Ctrl+B** | 선택 영역에 적용(커서만이면 문단 전체) |
| 이탤릭 | Ctrl+I | |
| 밑줄 | Ctrl+U | |
| 인용구 | **Ctrl+Alt+Q** | 문단에 커서만 두고 적용(블록) ⭐ |
| 구분선 | **Ctrl+Alt+H** | 빈 줄에서 삽입 ⭐ |
| 사진첨부 | **Ctrl+Alt+I** | 2단계 사진 자동에 사용 ⭐ |
| 임시저장 | **Ctrl+Shift+S** | 발행 아님(안전) ⭐ |
| 전체선택 | Ctrl+A | |
| 실행취소 / 다시실행 | Ctrl+Z / Ctrl+Y | |
| 왼/중앙/오른 정렬 | Ctrl+Alt+L / C / R | |

## 커서/선택
| 기능 | 단축키 |
|---|---|
| 이동 | ↑ ↓ ← → |
| 선택 | Shift+↑↓←→ |
| 행 맨앞 / 맨뒤 | Home / End |
| 선택취소 | ESC |
| 삭제 | Delete, Backspace |
| 줄바꿈 | Enter |

## 기타 첨부
| 기능 | 단축키 |
|---|---|
| 스티커 | Ctrl+Alt+K |
| 동영상 | Ctrl+Alt+M |
| 글감 검색 | Ctrl+Alt+S |
| 템플릿 목록 | Ctrl+Alt+T |

## ⚠️ 소제목은 단축키가 없음
- 소제목(대제목/소제목)은 이 목록에 단축키가 없음 → **문단서식 드롭다운(툴바) 클릭**으로만 가능.
- 즉 자동화 시: 인용구/구분선/굵게 = 단축키, **소제목 = 툴바 좌표 클릭**(publisher.js STYLE_SELECTORS.headOption).

## 적용 순서(자동화 설계)
1. 본문 클릭(진짜 커서) → **Ctrl+V** (서식HTML 붙여넣기: 텍스트+굵게 즉시 반영)
2. 마커 남긴 방식이면: 문단 순회하며
   - `> ` 문단 → 커서 두고 **Ctrl+Alt+Q**, 마커 제거
   - `---` 줄 → 줄 선택(Home→Shift+End) 삭제 → **Ctrl+Alt+H**
   - `## ` 문단 → **툴바 문단서식 → 소제목** (단축키 없음)
   - `**굵게**` → 단어 선택 후 **Ctrl+B**
3. **Ctrl+Shift+S**(임시저장). 발행은 사람이.
