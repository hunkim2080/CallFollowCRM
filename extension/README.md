# 시공막내 — 네이버 블로그 넣기 (크롬 확장)

시공막내에서 만든 블로그 글을 **네이버 블로그 글쓰기 창에 자동으로 넣어주는** 크롬 확장.
버전 **0.3.0** — 판다랭크식 **상주 패널** + **chrome.debugger 진짜 자동(진짜 Ctrl+V)**.

## 구조 (왜 이렇게)
- **왜 확장인가**: 웹은 남의 사이트(네이버)·내 PC를 못 만짐 → 확장만 가능.
- **왜 chrome.debugger인가**: 네이버는 "가짜(합성) 붙여넣기"를 거부하고 **진짜 Ctrl+V만** 받음.
  확장 content script 는 진짜 키를 못 누름 → **debugger(CDP)로 신뢰된 Ctrl+V** 를 보냄(사장님 publisher.js 를 확장 안에서 재현).
- **왜 팝업 아닌 패널인가**: 팝업은 다른 곳 누르면 사라져 내용이 날아감 → **에디터에 상주하는 패널**(판다랭크식).

## 설치 (개발자 모드)
1. 크롬 주소창 → **`chrome://extensions`**
2. **개발자 모드** 켜기 → **"압축해제된 확장 프로그램을 로드"** → 이 **`extension`** 폴더
3. 코드 갱신 시 이 페이지에서 **새로고침 ↻** (버전 **0.3.0** 확인)

## 쓰기
1. 네이버 블로그 **글쓰기** 창 열기 → 우하단에 🧩 **패널**이 자동으로 뜸 (툴바 아이콘으로 열기/닫기 토글)
2. 글 붙여넣기 (또는 **[예시 넣기]**)
3. **[✨ 자동으로 넣기]** → 확장이 알아서 본문에 붙여넣음 (진짜 Ctrl+V)
4. 임시저장/발행은 **직접**. (자동 발행 안 함 — 노하우 §0 원칙)

### ⚠️ 중요
- **개발자도구(F12)를 닫아두세요.** F12가 열려 있으면 디버거가 겹쳐 자동 넣기가 실패합니다.
- 자동 실행 중 상단에 **"이 확장이 브라우저를 디버깅 중"** 띠가 잠깐 떴다 사라집니다(정상).
