# 시공막내 — 네이버 블로그 넣기 (크롬 확장)

시공막내에서 만든 블로그 글을 **네이버 블로그 글쓰기 창에 통째로 자동으로 넣어주는** 크롬 확장.
버전 **0.8.0** — 제목·본문·서식·사진·임시저장까지 **버튼 몇 번**으로.

## 왜 이렇게 만들었나
- **왜 확장인가**: 웹은 보안상 남의 사이트(네이버)·내 PC를 못 만짐 → 확장만 가능.
- **왜 chrome.debugger인가**: 네이버는 "가짜(합성) 붙여넣기/클릭"을 거부하고 **진짜 키·클릭만** 받음.
  확장 content script 는 진짜 입력을 못 냄 → **debugger(CDP)로 신뢰된 Ctrl+V·클릭**을 보냄(사장님 publisher.js 를 확장 안에서 재현).
- **왜 상주 패널인가**: 팝업은 딴 데 누르면 사라져 내용이 날아감 → **에디터에 상주하는 패널**(판다랭크식).

## 되는 것 (0.8.0)
| 기능 | 방식 |
|---|---|
| **제목** | 제목란 진짜 클릭 + Input.insertText |
| **본문** | 서식HTML 클립보드 → 진짜 Ctrl+V |
| **굵게·인용구·구분선** | 위 붙여넣기로 그대로(네이버가 인라인/블록 인식) |
| **소제목** | 툴바 '본문▾ 문단 서식 → 소제목' 좌표 진짜 클릭 (단축키 없음) |
| **사진** | 이미지 클립보드 → 진짜 Ctrl+V, 글의 `[1] [2]` 자리표 위치에 (개별=SEO안전) |
| **나란히** | 한 줄 `[1] [2]`=사진 옆으로 드래그해 네이버 콜라주(se-imageStrip)로 묶음. 개별 유지+나란히 |
| **임시저장** | Ctrl+Shift+S (발행 아님) |

## 설치 (개발자 모드)
1. 크롬 주소창 → **`chrome://extensions`** → **개발자 모드** 켜기
2. **"압축해제된 확장 프로그램을 로드"** → 이 **`extension`** 폴더
3. 코드 갱신 시 이 페이지에서 **새로고침 ↻** (버전 확인)

## 쓰기
1. 네이버 블로그 **글쓰기** 열기 → 좌하단 🧩 **패널** (툴바 아이콘으로 열기/닫기)
2. **제목** 입력 → 글 붙여넣기(또는 **[예시 넣기]**) → **[✨ 자동으로 넣기]**
3. (사진) **[🖼 사진 고르기]** → **[📷 사진 넣기]** — 글의 `[1] [2]…` 자리표에 순서대로
4. **[💾 임시저장]** → 발행은 **직접** (자동 발행 안 함)

## ⚠️ 아주 중요
- **자동 진행 중엔 브라우저를 절대 건드리지 마세요.** 확장이 그 순간 **마우스·키보드를 원격조종**하는 거라, 클릭·타이핑·스크롤하면 충돌해서 중간에 멈춥니다. (패널에 "⏳ …건드리지 마세요!" 뜨는 동안 손 떼기)
- **개발자도구(F12)를 닫아두세요.** 열려 있으면 디버거가 겹쳐 실패("Another debugger").
- 자동 실행 중 상단 **"이 확장이 브라우저를 디버깅 중"** 띠는 잠깐 떴다 사라짐(정상).

## 파일
| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 설정 (MV3, debugger 권한) |
| `panel.js` | 상주 패널(content script, 셰도우DOM) |
| `background.js` | chrome.debugger 자동엔진(제목·본문·소제목·사진·저장) |
| `format.js` | 마커(##·&gt;·**·---) → 스마트에디터 HTML |
| `reference/` | 네이버 자동화 노하우 + 스마트에디터 단축키표 |
