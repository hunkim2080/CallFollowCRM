# 시공막내 — 네이버 블로그 넣기 (크롬 확장)

시공막내에서 만든 블로그 글을 **네이버 블로그 글쓰기 창에 서식(소제목·인용구·굵게·구분선)까지 넣어주는** 크롬 확장.

> **왜 확장인가**: 웹사이트는 보안상 "남의 사이트(네이버)"와 "내 PC 파일"을 못 만짐 → 확장만 가능.
> **왜 Ctrl+V인가**: 네이버 스마트에디터는 "합성(가짜) 붙여넣기"를 거부하고 **진짜 붙여넣기(Ctrl+V)만** 받아들임.
> 그래서 확장이 **진짜 클립보드에 네이버용 HTML을 담고 → 사장님이 진짜 Ctrl+V** 하는 구조. (네이버 자동화 노하우 3-7 기준)

---

## 설치 (개발자 모드)

1. 크롬 주소창 → **`chrome://extensions`**
2. 오른쪽 위 **"개발자 모드"** 켜기
3. **"압축해제된 확장 프로그램을 로드합니다"** → 이 **`extension`** 폴더 선택
4. 툴바에 🟢 **막** 아이콘 (안 보이면 퍼즐🧩 눌러 고정📌)
   - 코드 바뀌면 이 페이지에서 **새로고침 ↻** 눌러야 반영됨. (버전 확인: **0.2.0**)

## 쓰기

1. 네이버 블로그 **글쓰기** 창 열기 (`blog.naver.com …?Redirect=Write`)
2. 🟢 **막** 아이콘 클릭 → 글 붙여넣기 (또는 **[예시 넣기]** 로 테스트)
3. **[네이버용으로 복사]** 클릭
4. 네이버 본문 클릭 → **Ctrl+V** → 소제목·인용구·굵게·구분선까지 그대로 들어감
5. 훑어보고 **발행**은 직접. (자동 발행은 하지 않음 — 노하우 §0 원칙)

### 서식 마커
글에 아래를 쓰면 네이버 서식으로 변환됩니다 (시공막내 웹이 자동으로 붙여줄 예정):

| 마커 | 결과 |
|---|---|
| `## 소제목` | 소제목(h3) |
| `> 인용문` | 인용구 |
| `**강조**` | 굵게 |
| `---` | 구분선 |
| 빈 줄 | 문단 구분 |

### ⚡ 자동으로 넣어보기 (실험)
합성 붙여넣기를 자동 시도합니다. 네이버가 막으면(대개 막음) 실패 표시가 뜨고,
그때는 위 **[복사] → Ctrl+V** 로 하면 됩니다. (이 버튼은 "혹시 되나" 확인용)

## 파일 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 설정 (MV3) |
| `popup.html` / `popup.js` | 팝업 — 글 넣고 [복사] |
| `format.js` | 마커(##·&gt;·**·---) → 스마트에디터 HTML 변환 |
| `background.js` | (예약) si0in.kr 웹 → 확장 직접 연결용 |
| `icon128.png` | 툴바 아이콘 |
