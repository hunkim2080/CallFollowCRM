# 시공막내 — 네이버 블로그 넣기 (크롬 확장 · MVP)

시공막내에서 만든 블로그 글을 **네이버 블로그 글쓰기 창에 자동으로 넣어주는** 크롬 확장.
이번 MVP 는 **글(텍스트)만** 자동 삽입. 사진 자동 업로드는 다음 단계.

> 왜 확장이 필요한가: 웹사이트는 보안상 "남의 사이트(네이버)"와 "내 PC 파일"을 못 만짐.
> 그 벽을 넘는 게 확장프로그램뿐. (기획서: `docs/EXTENSION_PLAN_PROTO.html`)

---

## 설치 (개발자 모드로 불러오기 — 사장님 PC 크롬)

1. 크롬 주소창에 **`chrome://extensions`** 입력 → 엔터
2. 오른쪽 위 **"개발자 모드"** 토글 **켜기**
3. 왼쪽 위 **"압축해제된 확장 프로그램을 로드합니다"** 클릭
4. 이 **`extension`** 폴더를 선택
5. 툴바에 🟢 **막** 아이콘이 뜨면 성공 (안 보이면 퍼즐 아이콘 눌러 고정📌)

## 써보기

1. 네이버 블로그에서 **글쓰기** 창을 연다 (`blog.naver.com …`)
2. 본문 영역을 **한 번 클릭** (커서를 에디터에 둠)
3. 툴바의 🟢 **막** 아이콘 클릭 → 팝업이 뜸
4. **시공막내에서 만든 글을 붙여넣기** → **[네이버 글쓰기 창에 넣기]**
5. 네이버 본문에 글이 들어가면 성공. 훑어보고 **발행**은 직접.

## 안 될 때 (알려주실 것)

네이버 에디터는 구조가 복잡하고 자주 바뀌어서, 첫 시도에 안 들어갈 수 있어요.
그러면 아래를 알려주시면 바로 고칩니다:

1. 네이버 글쓰기 창에서 **F12**(개발자 도구) → **Console** 탭
2. `[시공막내]` 로 시작하는 로그가 있는지 (예: `로드됨 — … | 에디터 발견: true/false`)
3. **[넣기]** 눌렀을 때 팝업에 뜬 메시지 + 콘솔에 뜬 `[시공막내]` 메시지

→ "에디터 발견: false" 면 셀렉터를 네이버 현재 구조에 맞게 고치면 됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 설정 (MV3) |
| `popup.html` / `popup.js` | 아이콘 클릭 시 뜨는 창 (글 붙여넣기 + 넣기 버튼) |
| `content.js` | 네이버 에디터 페이지에 주입 — 실제로 글을 삽입 |
| `background.js` | (예약) 다음 단계에 si0in.kr 웹 → 확장 직접 연결용 |
| `icon128.png` | 툴바 아이콘 |
