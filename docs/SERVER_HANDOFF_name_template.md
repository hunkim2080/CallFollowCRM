# SERVER HANDOFF — 템플릿 제목 자동 작명 (POST /name-template)

대상: 맥미니 서버(cowork). 작은 Haiku 엔드포인트 1개.
앱측 현재 상태(2026-07-02, 안드로이드 Claude): `TemplateNameRepository`(POST /name-template) + 배선 완료.
- "자주 쓰는 문자 찾기 → 템플릿으로 저장" 시: 앱이 휴리스틱 제목으로 **즉시 저장**한 뒤, 이 엔드포인트로 **더 나은 제목**을 받아 갱신.
- 엔드포인트 없거나 실패하면 앱은 휴리스틱 제목 그대로 유지(오프라인·즉시 저장 보장). 즉 **서버는 "있으면 더 좋은" 보조**.

---

## 엔드포인트
`POST /name-template` — 문자 본문을 받아 짧은 제목을 반환. Haiku 4.5(저렴). 캐시 불필요(저장 시 1회).

## 입력 JSON
```json
{ "body": "6월 25일 일정확정을 위해 예약금 부탁드리겠습니다. ..." }
```

## 출력 JSON (엄격)
```json
{ "title": "예약금 안내" }
```
- `title` = 한글 짧은 제목(4~10자 권장). 설명·따옴표·줄바꿈 없이 제목만.
- 앱은 받은 title 을 20자로 자르고 개행 제거 후 그대로 저장. 빈값이면 휴리스틱 유지.

## 시스템 프롬프트 골자 (Claude Haiku 4.5)
```
너는 시공 사장님이 고객에게 보내는 문자에 짧은 제목을 붙이는 도우미다.
문자의 '용도'를 나타내는 한글 제목만 출력해라(4~10자). 예: "예약금 안내", "입금 확인", "견적 안내", "시공 전 안내", "부재중 안내".
설명·따옴표·문장부호 없이 제목 텍스트만. 모르면 "안내 문자".
```
user: `문자: {body}`

## 기술 메모
- Python 3.9 → `Optional[...]` 사용(PEP604 금지).
- Haiku 4.5, 입력~200/출력~10 토큰 ≈ 사실상 무시 가능한 비용.
- 실패해도 앱은 안전(휴리스틱 fallback). 서버는 200 + title 만 주면 됨.
- 경로는 루트(`/name-template`) — 앱이 `baseUrl/name-template` 로 호출(/api 아님, extract-pricing 과 동일 컨벤션).
