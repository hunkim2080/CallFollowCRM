## ① Play "출시 노트"(새로운 기능) — 사용자용, 그대로 붙여넣기

```
· 기본 문자 앱 설정 안내를 더 명확하게 개선했어요.
· 이용약관·개인정보처리방침을 앱 안에서 바로 볼 수 있어요(브라우저 없이도).
· 무료 체험 기간이 60일로 늘었어요.
· 알림 소리를 종류별로 고르고 미리 들어볼 수 있어요.
· 오늘의 현장 주소를 알림에 계속 표시해요.
· 여러 안정화 및 버그 수정.
```

## ② 심사 참고 — 권한 선언 폼 "검토 안내"에 넣을 문구 (재심사 통과용)

> ※ 이번 거부는 ①권한 요청 순서 ②등록정보 불일치 두 가지. ①은 코드로 고쳐 이 빌드에 반영,
>   ②는 아래 문구 + 스크린샷/데모영상으로 콘솔에서 보강. (상세: docs/PLAY_REJECT_2026-07-11_fix.md)

```
시공막내는 1인 시공업자(줄눈 등)용 고객관리(CRM) 앱입니다.
· 기본 SMS 핸들러: 첫 실행 시 런타임 권한보다 먼저 "기본 문자 앱으로 설정" 다이얼로그를 표시합니다.
  기본 문자 앱으로 지정하면 고객과 SMS/MMS(사진) 송수신, 부재중 자동응답 문자, 고객별 문자 대화 조회를 합니다.
· 발신번호 표시: READ_CALL_LOG 로 전화가 올 때/끝난 뒤 발신번호를 조회해, 저장된 고객이면
  이름·시공일·주소·최근 대화를 화면에 표시합니다.
· 스팸 감지: 수신 문자 중 광고성 문자를 자동 분류해 광고함으로 분리합니다.
데이터는 앱 기능 제공·개선 목적으로만 사용하며 제3자에게 판매·공유하지 않습니다.
```
