# 통계 탭 바이럴 — 타 AI 아이디어 수집용 프롬프트

> 아래 `---` 사이를 **통째로 복사**해서 다른 AI(ChatGPT·Gemini·Grok 등)에 붙여넣으세요.
> 앱을 전혀 모르는 AI 도 답할 수 있게 배경·데이터·제약을 다 넣어 뒀습니다.
> 여러 AI 에 같은 걸 넣고 답을 비교하면 좋습니다.

---

당신은 한국 소상공인용 모바일 앱의 제품 기획자입니다. 한국어로 답해주세요.

## 배경

나는 **줄눈 시공**을 하는 1인 사장입니다. 혼자 일합니다.
우리는 **1인 시공인**(줄눈·탄성코트·타일·도배·욕실리모델링 등, 남의 집에 들어가 고쳐주고 나오는 혼자 일하는 사장님들)을 위한 안드로이드 앱 **「시공막내」**를 만들고 있습니다.

앱이 지금 하는 일: 전화·문자로 들어온 상담 관리, 통화 녹음 AI 요약, 견적서·시공접수서 발송, 시공 일정 관리, 돈(계약금·잔금) 정산.

## 지금 풀려는 문제

앱에 **‘통계’ 탭**이 있는데 **아무도 안 들어갑니다.** 전환율·시공 종류 같은 나만 보는 숫자뿐이라서요.

이 탭을 **SNS 에 올리고 싶어지는 화면**으로 다시 만들고 싶습니다.
올리는 곳: 인스타그램 스토리·릴스·피드, 네이버 블로그, 당근마켓, 카카오톡·밴드 단톡방.

원하는 흐름:
시공인이 **스스로 올린다** → 그게 **영업**이 된다(손님이 보고 연락 옴) → 다른 시공인이 보고 **“저거 뭐로 만든 거야”** 하고 앱을 깐다.

## 쓸 수 있는 데이터 (여기 없는 건 없다고 보세요. 지어내지 마세요)

- **손님별**: 전화번호, 이름(있을 때만), 주소 텍스트, 시공 날짜, 시공 일수, 총금액·계약금·잔금, 완료 여부
- **현장 사진**: 사장님이 직접 올린 시공 전/후 사진
- **주소 → 동네 이름**: “경기도 화성시 동탄대로 250번길 18” → **“화성”** 으로 뽑는 기능이 이미 있음
- **세어지는 것**: 날짜별 문의 수, 날짜별 시공 건수, 올해 누적 건수, 다녀온 동네 개수
- **통화 녹음 AI 요약**, 손님에게 **보낸 문자 내용**
- **(선택)** 구글 타임라인 내보내기 파일(JSON) → **실제 다닌 길**과 **주행거리 km**. 단, 사장님이 직접 내보내기를 눌러야 함
- **사업자 정보**: 상호, 업종

**없는 것**: 실시간 위치 추적, 리뷰·별점, 직원·팀, 경쟁사 데이터, 손님 동의

## 이미 나온 안 (이것 말고 **새로운 것**을 주세요)

1. **「몇집했나」** — 이번 달 몇 집 시공했는지를 큰 숫자 하나로 (“12집”)
2. **다녀온 동네 지도** — 동네마다 점, 많이 간 곳은 큰 점. 다닌 범위에 따라 (동네 하나 / 수도권 / 전국) 틀이 바뀜
3. **실제 다닌 길** — 구글 타임라인 파일로 도로를 따라가는 선 + 🚛 움직이는 애니메이션
4. **주행거리** — 오늘 62km / 이번 주 318km / 이번 달 1,240km
5. **현장 사진 위에 얹는 기록 카드** — 배경이 투명한 PNG 를 복사해서 인스타 스토리에서 내 현장 사진 위에 붙여넣기
6. **앱이 먼저 내밀기** — 시공 끝낸 직후 / 매달 1일 아침 / 처음 간 동네 / 100집째에 “카드 만들어 뒀어요”
7. **해시태그 자동 생성** — #몇집했나 #줄눈시공 #화성줄눈 …

## 우리가 참고한 것 (유행하는 것들)

- **Timeline Visualizer** — 구글 타임라인 파일을 넣으면 내가 다닌 경로가 지도 위에 그려지는 영상을 만들어 줌. 한국에서 **“역마살 측정기”** 라는 이름으로 인스타에서 유행(조회수 2만+)
- **KYRO** — 러닝 앱. 달린 경로가 감싼 넓이를 **“영토”** 로 주고(“달린 만큼 내 땅이 된다”), 기록을 **배경 투명 PNG** 로 뽑아 인스타 스토리에서 자기 사진 위에 붙이게 함

## 반드시 지켜야 할 것

- **말투**: 어르신도 읽는 쉬운 우리말. 영어 마케팅 용어(리텐션·인게이지먼트 등) 쓰지 마세요
- **브랜드**: “자리는 막내, 머리는 똑똑한” — 앱은 사장님의 **막내 직원** 같은 존재. ‘비서’라는 말은 안 씁니다
- **디자인 톤**: 흰 바탕 + 파랑. 토스처럼 담백하게. **게임·스포츠 느낌 아님**
- **보는 사람은 결국 ‘손님’입니다.** 손님이 보고 신뢰가 깨지면 실패입니다
- **한국 상황** 기준 (인스타·네이버 블로그·당근·카톡이 주 무대)
- 앱에 **없는 데이터**를 전제한 아이디어는 쓸모없습니다
