## 서버 엔드포인트 (전부 구현·검증 완료)

### 1) 링크 발급 — 업무폰A
`POST /api/mirror/issue` `{ owner_phone, label, tint?, pin? }`
→ `{ ok, token, url, label, pin?, pinNotice? }`
- 이미 그 업무폰이 링크에 속해 있으면 **기존 것 재사용**(label만 갱신). 중복 발급 안 됨.
- `pin` 안 보내면 **서버가 4자리를 만들어 이 응답에서 딱 한 번** 내려줍니다. 해시만 저장하므로 **다시는 못 봅니다.**
  → 앱은 이 값을 **사장님께 크게 보여주고**("본폰에서 처음 열 때 입력하세요"), **저장하지 마세요.**
- 사장님이 직접 정하고 싶어하면 `pin`(4자리 숫자)을 보내면 됩니다.
- `url` 예: `https://api.si0in.kr/mirror/L8wTTjdywtns` → 문자/카톡으로 본폰에 공유.

### 2) 두 번째 사업장 합치기
- 업무폰A(또는 이미 등록된 폰): `POST /api/mirror/pair/code` `{ owner_phone }` → `{ code, validMinutes: 10 }`
- 업무폰B: `POST /api/mirror/pair` `{ code, owner_phone, label, tint }` → 같은 token 에 합류
- 코드는 6자리·10분·1회용. SMS 불필요(사장님이 직접 보고 입력).

### 3) 스냅샷 push — **앱의 핵심 작업**
`POST /api/mirror/snapshot`
```json
{
  "owner_phone": "01011112222",
  "label": "디테일라인",
  "items": [
    {"date":"2026-07-15","time":"09:00","days":2,"name":"홍길동",
     "address":"화성시 동탄1로 2","phone":"01055556666",
     "memo":"현관 비번 1234#","completed":false}
  ],
  "money": {"todayIn": 300000, "unpaid": 1200000, "unpaidCount": 2}
}
```
- **덮어쓰기 방식**(diff 없음) — 팀원 `schedule-snapshot` 과 동일 컨셉. 항상 전체를 보내세요.
- `date`= `YYYY-MM-DD` (필수, 없으면 그 건 무시됨). `days`≥2 면 뷰어가 **자동으로 날짜를 펼쳐** 캘린더에 N일 표시(1/2일차).
- `time`("HH:MM")·`phone`·`memo`·`completed` 는 선택. `money` 는 사업장별로 보내면 뷰어가 **합산**해서 보여줍니다.
- 트리거(원 설계대로): `observeScheduled()` 구독 → **30초 디바운스 + 해시 비교 시에만 POST** + WorkManager 12h 백업 push.

### 4) 폐기 (본폰 분실)
`POST /api/mirror/revoke` `{ owner_phone, token }` → 이후 그 링크는 **410**. 설정에 [링크 폐기] 버튼 필수.

## 본폰 화면 (서버가 이미 다 그림 — 앱 작업 없음)
`GET /mirror/{token}` → 비번 게이트 → 읽기전용 통합 캘린더.
사업장 칩(전체/사업장별 색점) · 돈 요약 2칸 · 월 캘린더(날짜별 사업장 색 점) · 날짜 탭 → 현장 카드(이름·시간·N일차·주소·전화 탭하면 통화·메모) · **"마지막 업데이트: 디테일라인 3분 전 · 하우스픽 1시간 전"** · 60초 자동 새로고침 · PWA(홈화면 추가).
**수정 UI 일절 없음.**

## 앱 UI 제안
- 더보기 → **[본폰에서 일정 보기]** (기본 꺼짐) → 켜면 `issue` → **비번 4자리 크게 표시** + [링크 공유] (문자/카톡).
- 같은 화면에 [사업장 추가] → `pair/code` 로 6자리 표시, 업무폰B에서 입력.
- 하단에 [링크 폐기] (빨강) + "마지막 전송: n분 전".

## 주의
- Python 3.9 서버 — 서버쪽 타입은 `Optional[...]` 유지 중(앱 무관, 참고).
- `owner_phone` 은 서버가 `_norm_phone` 으로 정규화합니다(하이픈 유무 무관).
- 비번 오입력 10회 → 10분 차단. 정상 사용에는 영향 없음.
