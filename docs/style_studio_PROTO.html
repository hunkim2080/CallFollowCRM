〰️글 구성·어미·어투✎ 수정 가능
· 글 흐름 — [고객 고민 → 현장 진단 → 상담·결정 → 시공 과정 → 시공 전/후 → 정직한 마무리] 순서. 문제 상황을 먼저 꺼내 공감을 만들고, 마지막은 “비슷한 고민이면 사진 보내주세요”로 맺어요.

· 종결 어미 — ~어요 / ~습니다(정보 전달) 섞어 쓰고, 권유는 ~드릴게요 / ~해요.

· 리액션·이모지 — 이모지는 절제(🚽✅ 정도), 강조는 문장으로. 문단은 짧게 끊어 모바일에서 읽기 쉽게.

  • 🎯
    플랫폼마다 따로 학습 (사장님 요청)
    블로그=글 주소 / 인스타·스레드=계정 or 캡션 붙여넣기. 플랫폼마다 톤이 다르니 각각.
  • 🧬
    깊게 분석 → 수정 가능한 리포트
    페르소나·글 흐름·종결어미·어투·리액션·이모지·해시태그 습관까지. 리포트는 사장님이 직접 고칠 수 있어요(맘에 안 드는 줄만 수정).
  • ✨
    저장하면 [글 만들기]에 자동 반영
    저장한 스타일대로 그 플랫폼 글이 나와요. “사장님이 직접 쓴 것처럼” 일관.
  • 💳
    분석·생성 모두 본인 Gemini 키
    분석도 owner 키로 → 비용 본인. 원문은 톤 학습에만 쓰고 저장은 요약된 스타일만.
이 방향이면 될까요? PandaRank 처럼 “연결→깊게 분석→수정 가능한 리포트→그 톤으로 생성” 흐름을, 우리 3플랫폼 + 시공 맥락으로. 좋으면 마이페이지 ‘블로그 톤’ 자리를 이 ‘스타일 학습’으로 키워서 코워크에 넘길게요.
