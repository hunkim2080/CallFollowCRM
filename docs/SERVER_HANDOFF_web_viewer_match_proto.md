## 프로토에서 가져갈 부분 (시각 스펙)

`docs/web_photo_calendar_PROTO.html` 안에서:
- **`:root` 색 토큰**(4~6줄): `--blue:#3182F6`, `--blue-soft:#EEF4FF`, `--page:#EAEDF1`, `--card:#FFFFFF`, `--ink:#0B0F19`, `--t2/t3`, `--line`, `--ok`, `--purple`, `--amber` + 다크모드 블록. **이 팔레트 그대로.**
- **캘린더**(`.cal`,`.cell`,`.cell.job`(파란 배경),`.dot`,`.cam` 📷,`.legend`): 시공 있는 날 파란칩·점, 사진 올라온 날 📷.
- **"이 달 시공 현장" 목록**(`.daylist`,`.drow`): 한 줄 = **날짜(8/15 큰 파랑)·아파트명(굵게)·이름·시공종류·📷장수·완료/진행 badge**. 선택된 현장 파란 테두리(`.drow.on`). ← 지금 스샷의 밋밋한 리스트를 이걸로.
- **사진 그리드**(`.grid`,`.gcard`): 시공 전/후 라벨, **올린사람 뱃지**(사장님=파랑·팀원=초록·**협업 사장=보라 `협업·박사장`**), 다운로드 아이콘.
- **부위 칩**(`.partpick`,`.pchip`): 관리형(추가·삭제·순서) — 이미 반영했다니 스타일만 프로토 맞춤.
- **다운로드 바**(`.dlbar`): "☑ N장 선택 · 파일명 예시 · 용량", 전체선택, 📥 다운로드 버튼. **화질 토글 없음(1280 통일)**.
- **문구 verbatim**: "이 달 시공 현장", "시공 전/후 = 올린 시간순 자동 구분", "선택 N장 다운로드", 뷰어 안내문 등 프로토 글자 그대로.

> ⚠️ 프로토의 **브라우저 크롬 목업(`.chrome`,`.browser`)·로그인 데모(`.login`,`.qr`)·페이지 하단 설명(`.legend2`/footer)** 은 목업용 장식 — 실제 페이지엔 불필요. **캘린더+목록+사진그리드+다운로드+부위칩**의 CSS·배치·문구만 가져가면 됨.
