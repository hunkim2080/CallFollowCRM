## v3 의 3가지 무게중심

1. **시장 재정의** — "줄눈 SaaS" 가 아니라 **"비사무직 1인 현장 사업자 운영 OS"**. 줄눈은 진입 wedge, 본질은 시공·인테리어·설치 기사 전체.
2. **데이터 vertical moat** — AI 가 moat 가 아니다. 통화·견적·일정·협업·일당·정산 데이터가 쌓이는 게 moat. AI 는 그 데이터를 활용하는 수단.
3. **Wedge 4개 명확화** — 부재중 / 일정 / 통화 / 협업. 나머지 (정산·통계·견적·모집) 는 락인·확장 가치로 위치 재조정.

**왼쪽 (시간순)**:

> 오전 10시. 줄눈 시작.

> 부재중 5통. 그 사이 다른 사장이 그 일을 받아갑니다.
>

> "그 사장님 25만 원 말했었나? 30이라 했었나?"
>
> 저녁 9시. 노트에 정산.
> 어제 그 고객한테 입금 받았던가?

**오른쪽 (페인 → 결과)**:
| 페인 | 비즈니스 손실 |
|---|---|
| 시공 중 손 없음 → 부재중 | 고객 이탈 (즉시 다른 사장으로) |
| 메시지 외움 → 약속 깨짐 | 신뢰 손실 → 추천 끊김 |

| 일정 충돌 → 큰 현장 거절 | 매출 상한 갇힘 |
| 정산 누락 | 재청구 못 함 → 손실 |

> 💡 핵심: 시공 사장은 **"손으로 일하는 사람"**. 책상에서 만든 SaaS 는 이 페인을 짚지 못합니다.

# Slide 4 — 시장 재정의 ⭐⭐⭐ (가장 중요)

**제목**: 줄눈 앱이 아닙니다. 비사무직 1인 현장 사업자 시장입니다.

**3단 시장 정의 (TAM / SAM / SOM)**:

**TAM — 한국 비사무직 1인 현장 사업자 (5년 내 도달 가능)**
> 시공·인테리어 + 설치 기사 + 출장 서비스 (수리·청소·이사)
> 추정 [N] 만 명 — 통계청 KOSIS / 국세통계 [출처 확정 필요]
> 1인 1대 폰 = SaaS 도달 가능 시장

**SAM — 시공·인테리어 1인 사업자 (3년 내)**
> 줄눈·타일·도배·페인트·욕실 리모델링·가구 설치
> 추정 [N] 만 명 — 인테리어협회 / 산업통계 [출처]
> 같은 워크플로우 (현장·통화·견적·협업) 공유

**SOM — 줄눈·타일·도배 (12개월 내)**
> 추정 [N] 만 명
> 대표 본인 직종 + 인접 직종 = 가장 깊은 검증 가능

**왜 이 시장 전체로 확장 가능한가**:
- 같은 도구 (운전·작업도구로 손 묶임) → 같은 부재중 / 통화 페인
- 같은 비즈니스 모델 (개별 견적·정찰제 어려움) → 분쟁·정산 페인 공통
- 같은 협업 구조 (큰 현장 = 사장끼리 분담) → 네트워크 가치 공통

> 💡 진입 전략: 줄눈 → 시공 직종 → 비사무직 전반. 각 직종 핵심 페인이 90% 일치.

> 💡 "경쟁자가 없다" 가 아니라 — **"기존 대안의 사용자 모델이 다르다"** 가 우리 입장.

# Slide 6 — Wedge: 4개 핵심 기능 ⭐⭐

**제목**: 처음 30일에 사용자를 락인시키는 4가지

**4박스 그리드**:

📵 **① 손이 없을 때 — 부재중 자동 답장**
시공 중 부재중 → 미리 만든 템플릿이 자동 발송.
"지금 시공 중이에요. 16:00 연락드릴게요."
→ **고객 이탈 방지** = 사장이 가장 먼저 느끼는 가치.

📅 **② 문자 한 통이 일정으로 — 자동 등록**
고객 메시지 → 번호·날짜·시간 자동 인식 → 한 탭으로 일정.
머리에 안 외워도 됨.
→ **약속 누락 방지** = 매일 쓰는 락인 기능.

🎙️ **③ 통화는 끝나면 자동 정리 — 화자 구분**
🙋 고객 / 🏢 사장님 구분된 요약 + 핵심 약속 자동 추출.
6개월 후에도 키워드 검색.
→ **분쟁 방지** = 정찰제 못 하는 시공 시장의 결정적 가치.

🤝 **④ 협업 사장 캘린더 자동 동기화**
협업 요청 → 수락 시 양쪽 캘린더 자동 등록 → 2h 전 자동 알림.
잊을 래야 잊을 수 없음.
→ **네트워크 확장 = 시공막내의 moat 진입점**.

**오른쪽 박스 (왜 이 4개인가)**:
- 1·2·3 = **개인 자동화 락인** — 매일 쓰는 가치 = 이탈률 ↓
- 4 = **네트워크 확장 진입점** — 다른 사장 끌어옴 = 바이럴 + Network Effect

# Slide 7 — 보조 기능 (락인·확장 가치)

**제목**: 락인 후 가치 — 정산·통계·견적·모집

**4박스 (Wedge 후 사용자가 발견하는 가치)**:

💰 **정산 탭**
고객별 시공 금액·입금 여부·일당 정산 — 한 화면에. 매달 세금 신고 헷갈리지 않음.

📊 **커뮤니티 통계 (지역·직종 시장 인텔리전스)**
본인 매출 추이 + 같은 지역·직종 사장 평균. "비수기인지 내가 못해서인지" 데이터로 판단.
→ **사용자 늘수록 통계 정확도 ↑ — 데이터 vertical 의 핵심**.

📝 **견적서 + 접수 자동화**
견적서 작성 → 고객에게 링크 전송 → 그 자리에서 접수. "더 이상 다른 앱 안 써도 됨."

👷 **일당 모집 (broadcast → 지원 → 선택)**
잡일·인력 부족 시 동네 사장에게 일괄 모집. 함께한 적·받은 일당 가산점 기반 선택.

> 💡 이 4개는 **wedge 이후의 가치**. 사용자가 30일 이상 쓰면서 자연스럽게 발견 → 이탈 차단 + 상위 티어 전환 동인.

# Slide 8 — 데이터 Vertical = Moat ⭐⭐⭐

**제목**: AI 가 아니라, 쌓이는 데이터가 진짜 방어력입니다

> 다른 팀도 Whisper / Gemini / Claude 는 쓸 수 있습니다.
> 그들이 절대 못 가지는 것은 — **시공 현장에서 매일 쌓이는 운영 데이터** 입니다.

**6개 데이터 자산 박스**:

| 데이터 | 비즈니스 가치 |
|---|---|
| 통화 패턴 (시공 도메인 발화) | 톤 학습 정확도 → 답장 추천 품질 ↑ |
| 견적·계약 패턴 | 직종·지역별 가격 시그널 |
| 일정 빈도 | 성수기·비수기 매크로 시그널 |
| 협업 이력 | 사장-사장 신뢰 그래프 (대체 불가) |
| 일당 거래 이력 | 일당 사장 신뢰도 score |
| 지역 수요 분포 | B2B 인테리어 업체·정부 정책 자문 가능 |

**진정한 moat 구조**:
```
사용자 ↑ → 데이터 ↑ → 매칭·통계 정확도 ↑ → 가입 동기 ↑ → 사용자 ↑
                  ↘ 시장 리포트·B2B 데이터 사업
                  ↘ 일당 신뢰도·협업 이력 = 이탈 비용 ↑
```

> 💡 핵심: 후발 대기업이 같은 AI 를 써도 — **시공 사장 데이터는 못 가짐**. 그게 진짜 진입장벽.

# Slide 9 — Network Effect

**제목**: 사장이 늘수록 모두가 더 강해집니다

**3축 동시 강화**:

**축 1: 협업 매칭**
사장 1명 → 솔로 / 10명 → 동네 협업 / 100명 → 직종 협업 / 1,000명 → 동네별 즉시 매칭.

**축 2: 일당 양면 시장**
모집 사장 ↔ 일당 사장 — broadcast → 선착순 지원 → 가산점 기반 선택.
**"함께한 적 7번 · 받은 일당 175만 원"** = 거래 이력 자체가 신뢰 자본.

**축 3: 데이터 정확도**
같은 지역·직종 사장이 늘수록 — 통계 정확도 ↑ → 가입 동기 ↑.
사용자 1,000명 단위에서 **B2B 시장 리포트** 가능.

**다이어그램** (필수 시각화):
```
        [협업 매칭]
              ↑
[데이터] ←→ 사용자 ←→ [일당 양면]
              ↓
        [이력 락인]
```
세 축이 동시에 강해지는 구조 — 분리된 piece 가 아니라 같은 사용자가 동시에 세 가치를 받음.

# Slide 10 — Founder-Market Fit + 유통 채널 ⭐⭐⭐

**제목**: 제가 그 시장이고, 그 시장으로 들어가는 문도 갖고 있습니다

**왼쪽 — Founder-Market Fit**:
> 김상훈 / 디테일라인 줄눈 시공업 대표
>
> 이 앱은 책상에서 기획한 CRM 이 아닙니다.
> 현장에서 놓친 전화와 깨진 약속, 분쟁난 견적, 외운다고 외워지지 않는 정산에서 시작됐습니다.
>
> 모든 기능은 — 양 손에 코킹총 들고도 쓸 수 있나 / 운전 중 한 손으로 가능한가 / 머리에 외울 필요가 없나 — 이 3가지 기준으로 설계됐습니다.

**오른쪽 — 초기 유통 채널 (투자자가 가장 보고 싶어함)**:

| 채널 | 접근 가능성 |
|---|---|
| 시공 카페·커뮤니티 (네이버 카페 등) | ✅ 본인 운영 멤버 — 직접 글 가능 |
| 디테일라인 브랜드 신뢰 | ✅ 줄눈 사장 네트워크 안에서 인지도 |
| 줄눈·타일·도배 사장 인맥 | ✅ 베타 추천·인터뷰 풀 |
| 유튜브·블로그 | ✅ 시공 콘텐츠 운영 가능 |
| 시공 박람회·교육장 | ✅ 직접 접근 |
| 협업 사장 추천 | ✅ Network Effect 의 바이럴 채널 |

> 💡 투자자 관점: 제품 자체보다 **"초기 유통이 가능한가"** 가 더 중요. 책상 창업자가 가장 어려워하는 게 이 시장 진입 자체. 그 문이 이미 열려 있음.

## A4. FAQ (예상 질문 답변)

**Q. 시장이 너무 작지 않나?**
A. 줄눈은 SOM (Beachhead). SAM 은 시공·인테리어, TAM 은 비사무직 1인 사업자 전체. 직종별 페인 90% 일치로 확장 가능.

**Q. 왜 사장님들이 9.9만원을 낼까?**
A. 부재중 답장 1건 → 시공 1건 매출 [N]만원. 분쟁 1건 방지 → 손실 [N]만원. 본전 회수 매우 빠름.

**Q. 차별화 / 진입장벽이 뭔가?**
A. AI 가 아닌 데이터 vertical. 통화·견적·일정·협업 데이터가 쌓이는 게 moat. 후발 주자가 같은 AI 써도 사장 데이터 못 가짐.

**Q. 팀에 다른 인력은?**
A. 시드 자금으로 iOS + 그로스 채용. 대표가 도메인 + 풀스택 동시 수행 가능한 게 핵심 강점.

**Q. 트랙션이 약한데?**
A. 다음 6주 검증 계획 (Slide 13). 본격 시드 IR 은 그 결과 기반으로 진행.
