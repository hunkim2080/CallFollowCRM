# 안드로이드 핸드오프 — 통화녹음 폴더 자동 감지 + 가이드 UI (cowork → android, 2026-06-21)

## 사장님 보고

> "통화요약 기능을 사용하고 싶지만 **자기 녹음이 어느 파일이 되고 있는지도 잘 모르더라고**.."

= 베타 사용자가:
- 통화 끝남 → 폰이 자동 녹음 (또는 안 녹음)
- 녹음 파일 어디 저장되는지 모름
- 시공막내 앱이 그 파일 찾으려 해도 사용자가 폴더 선택 안 해줘서 못 찾음
- 결과: 통화요약 누르면 "녹음 파일 못 찾았어요" 토스트

= **앱 UX 문제**. 사용자 입장에서 "녹음 폴더 어디?" 가 가장 큰 진입 장벽.

## 안드로이드 측 요청 — 3단계

### 1. 자동 감지 (앱 첫 진입 또는 설정 들어갔을 때)

**알려진 통화녹음 경로** 자동 스캔 (Android 11+ MediaStore + SAF):
- 갤럭시 기본 녹음: `/storage/emulated/0/Recordings/Call/`
- 갤럭시 옛 폴더: `/storage/emulated/0/Sounds/Call/`
- 에이닷 녹음: `/storage/emulated/0/Recordings/Adot/` (또는 패키지별)
- 통화녹음 by 갤럭시: `/storage/emulated/0/Recordings/CallRecord/`
- T전화: `/storage/emulated/0/SKT/`

스캔해서 **`.m4a` / `.mp3` / `.amr` 파일이 있는 폴더 첫 1개** 자동 선택. 사용자한테 묻지 않고 자동 연결.

### 2. 자동 감지 실패 시 — 친절한 가이드 화면

자동 감지 실패하면 (또는 권한 X) → 가이드 화면:

```
┌─────────────────────────────────────┐
│  🎙️ 녹음 파일 찾기 도움말             │
│                                     │
│  통화 녹음 파일이 어디에 저장되는지   │
│  찾아드릴게요.                       │
│                                     │
│  ▼ 갤럭시 사용자                     │
│  1. 전화 앱 열기                      │
│  2. 통화 한 번 → 녹음 버튼 누름        │
│  3. "내 파일" 앱 → "통화 녹음" 폴더    │
│                                     │
│  ▼ 그 외 폰                          │
│  1. "내 파일" 앱 → 검색에 "녹음"      │
│  2. .m4a 또는 .amr 파일 찾기          │
│  3. 그 파일이 있는 폴더 = 녹음 폴더    │
│                                     │
│  [폴더 직접 고르기]   [도움 영상 보기]  │
└─────────────────────────────────────┘
```

**[폴더 직접 고르기]** = `OpenDocumentTree` SAF intent → 사용자가 폴더 선택 → 시공막내가 그 폴더 권한 받음.

**[도움 영상 보기]** = 1~2분짜리 짧은 영상 (사장님이 녹화 + YouTube 또는 si0in.kr/help/recording 호스팅). 이건 사장님 작업.

### 3. 연결 후 — "녹음 OK" 상태 표시

설정 화면에 항상:
```
🎙️ 녹음 폴더 연결: ✓ 갤럭시 통화 녹음
   → 최근 녹음 3개 보기 (디버그)
```

이거 보이면 사용자가 "잘 연결됐구나" 안심. 안 보이면 "도움말 보기" 안내.

### 4. 통화 끝나면 자동 처리 (이미 있다면 OK)

통화 끝나고 10~30초 뒤 워커가 새 녹음 파일 감지 → 자동으로 `/api/call-audio-summary` 호출 → 결과 푸시.

이미 안드로이드 측에 있는 듯 (SYNC 06-20 02:00 의 `AdotFolderScanner` + ChatViewModel `summarizeCallNow`). 그치만 폴더 연결 안 됐으면 무용. = **1, 2번이 진입 장벽**.

## 산출물

1. 자동 감지 로직 (`RecordingFolderDetector.kt` 또는 같은 이름) — 알려진 경로 5~6개 자동 스캔
2. 가이드 화면 (Compose) — 자동 감지 실패 시 표시
3. 설정 화면에 "녹음 폴더 연결: ✓/✗" 상태 표시 (이미 있다면 더 명확하게)
4. 첫 진입 시 자동 감지 시도 → 성공 시 silent, 실패 시 가이드 다이얼로그

## 검증

베타 사용자 1명한테 핸드오프 후 빌드 깔고:
- 자동 감지 성공? = silent, 통화 끝나면 요약 자동.
- 실패? = 가이드 화면이 친절히 안내.

## 서버 측 영향
