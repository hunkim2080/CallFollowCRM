# Play 심사 거부 (2026-07-11) 원인·해결 — 민감 권한(SMS/통화기록)

앱: 시공막내 · 시공 상담 비서 (`com.detailline.callfollowcrm`)
상태: **거부됨** (이전 버전은 계속 제공). 적용일 7월 10일.
정책: **민감한 정보에 액세스하는 권한 및 API 정책** (SMS/통화기록)

구글이 지적한 문제는 **2가지**. 하나는 앱 코드, 하나는 콘솔 등록정보.

---

## ① [코드] 기본 핸들러 메시지가 런타임 권한보다 먼저 트리거되지 않음 → **수정 완료**

### 원인
- 앱을 "기본 SMS 핸들러"로 신고했는데, 첫 화면(온보딩)에서 **곧바로 문자/통화기록 런타임 권한 창부터** 띄웠다.
- "시공막내를 기본 문자 앱으로 설정?" 다이얼로그는 설정 안에만 있어 **순서가 반대**였다.
- 구글 규칙: 기본 핸들러인 앱은 **런타임 권한 요청보다 먼저 "기본 문자 앱으로 설정" 다이얼로그를 띄워야 함.**

### 수정 (2026-07-11, `OnboardingPermissionScreen.kt`)
- "권한 허용하고 시작하기" → 순서 고정:
  1. **① ROLE_SMS(기본 문자 앱) 다이얼로그 먼저** (`DefaultSmsAppHelper.createRequestIntent`)
  2. (수락/거부 무관, 다이얼로그 닫히면) **② 런타임 권한**(통화기록·전화상태·알림)
- 기본 문자 앱이 되면 SMS 그룹 권한(READ_SMS/RECEIVE_SMS…)은 시스템이 **자동 부여** → 창이 아예 안 뜸.
- 이미 기본 앱이거나 미지원 구형 기기면 곧바로 런타임 권한으로 폴백.
- 온보딩 권한 카드에 "📨 기본 문자 앱 — 다음 화면에서 여쭤봐요" 안내 한 줄 추가.

> 첫 실행 권한 요청 경로는 온보딩 화면 하나뿐(MainActivity는 직접 요청 안 함)이라 이 한 곳 수정으로 순서 위반이 사라진다.

---

## ② [콘솔] 요청된 권한이 앱의 핵심 기능과 일치하지 않음 → **사장님 콘솔 작업 필요**

### 원인
- 권한 선언 폼에 체크한 **핵심 기능 2개**:
  - ✅ 기본 SMS 핸들러
  - ✅ 발신번호 표시, 스팸 감지 및 차단  ← READ_CALL_LOG 는 이걸로 정당화됨
- 구글: "**스토어 등록정보(소개글·스크린샷)가 선언한 핵심 기능과 일치하지 않는다.**"
  즉 앱 소개에 "기본 문자 앱 / 발신번호 표시 / 스팸 감지" 기능이 **눈에 안 보인다**는 뜻.

### 해결 (콘솔 등록정보에서)
두 신고 기능(기본 SMS 핸들러 + 발신번호 표시·스팸)을 **그대로 유지**하되(READ_CALL_LOG 때문에 발신번호 표시 신고는 꼭 필요),
**스토어 등록정보와 데모영상이 그 기능을 명확히 보여주게** 만든다.

**A. 앱 설명(전체 설명)에 아래 문단을 포함** — 아래 "붙여넣기용 소개글" 참고.
   - 기본 문자 앱: 고객 문자·사진(MMS)을 시공막내에서 직접 받고 관리
   - 발신번호 표시: 전화가 오면 고객 정보(이름·시공일·주소) 카드 표시
   - 스팸 감지: 광고 문자 자동으로 걸러내 상담함을 깨끗하게

**B. 스크린샷 추가/교체** — 아래 3장이 등록정보에 보이게:
   1. 고객과 주고받은 문자·사진 대화 화면 (기본 문자 앱)
   2. 전화 올 때 뜨는 고객 정보 카드 (발신번호 표시)
   3. 광고 문자가 광고함으로 걸러진 상담함 (스팸 감지)

**C. 데모영상 (거의 필수)** — 기본 SMS/통화기록 앱은 구글이 데모영상을 요구하는 경우가 많다.
   30초~1분 화면녹화로 아래를 순서대로 보여주면 됨:
   1. 앱을 기본 문자 앱으로 설정하는 장면
   2. 고객 문자/사진을 앱에서 받는 장면
   3. 전화 올 때 고객 카드 뜨는 장면
   4. 광고 문자가 걸러지는 장면
   - 유튜브(미등록/일부공개)에 올리고 그 링크를 **권한 선언 폼의 "동영상 안내" 칸**(현재 비어 있음)에 넣기.

**D. 검토 안내 칸 보강** — 현재 있는 안내에 발신번호 표시·스팸 감지 설명도 한 줄씩 추가(아래 참고).

## 붙여넣기용 — 스토어 설명 문단 (전체 설명에 삽입)

```
■ 기본 문자 앱으로 고객 상담을 한 곳에서
시공막내를 기본 문자 앱으로 지정하면, 고객이 보낸 문자와 사진(MMS)을 앱에서 바로 받아
고객별 대화로 정리해 보여줍니다. 부재중 전화가 오면 안내 문자를 자동으로 준비해 드립니다.

■ 전화가 오면 누구인지 한눈에 (발신번호 표시)
전화가 울릴 때 저장된 고객이면 이름·시공 예정일·주소·최근 대화를 카드로 띄워
"몇 동 몇 호였지?" 를 통화 전에 바로 확인합니다.

■ 광고 문자는 자동으로 걸러서 (스팸 감지)
대출·홍보 같은 광고 문자를 자동으로 가려 광고함으로 옮기고, 진짜 고객 상담만
상담함에 남깁니다.
```

## 붙여넣기용 — 권한 선언 폼 "검토 안내" 보강 문구

```
시공막내는 1인 시공업자(줄눈 등)용 고객관리(CRM) 앱입니다.
· 기본 SMS 핸들러: 사용자가 앱을 기본 문자앱으로 지정하면 고객과 SMS/MMS(사진) 송수신,
  부재중 자동응답 문자, 고객별 문자 대화 조회를 합니다.
· 발신번호 표시: READ_CALL_LOG 로 전화가 올 때/끝난 뒤 발신번호를 조회해 저장된 고객이면
  이름·시공일·주소·최근 대화를 화면에 표시합니다(발신번호 표시).
· 스팸 감지: 수신 문자 중 광고성 문자를 자동 분류해 광고함으로 분리합니다.
데이터는 앱 기능 제공·개선 목적으로만 사용하며 제3자에게 판매·공유하지 않습니다.
```
