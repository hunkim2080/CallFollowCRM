# 🩺 품질 계기판 — 주마다 쌓는 숫자

**빌드가 직접 재서 적는다**(`gradlew health`). 제가 "괜찮습니다" 라고 말하는 대신
**숫자가 파일에 남는다** — 사장님은 느낌이 아니라 숫자로 보시고, 저는 거짓 보고를 할 수 없다.
(2026-10-02 사장님 "어떻게 해야 상위권보다 더 높은 평을 받을 수 있어?")

⚠️ 이건 **가드가 아니다** — 아무것도 막지 않는다. 막는 건 가드 7개가 한다.

## 무엇을 보나
- **2,000줄 넘는 파일** · **같은 걸 두 번 적은 곳** → 줄어야 좋다
- **자동 시험** · **공용 목록** · **실패를 말하는 저장** → 늘어야 좋다
- **조용한 저장(아직 안 본 것)** → 0 이 목표
- **배포할 때 시험이 도나** → 늘 ✅ 여야 한다
