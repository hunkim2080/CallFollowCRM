🧩 시공막내 · 크롬 확장프로그램 기획

글+사진을 네이버 블로그에 원클릭 자동 발행

시공막내 웹에서 만든 글(사진 자리 포함) + 사진을, 네이버 블로그 글쓰기 창에 버튼 한 번으로 그대로 꽂아주는 확장프로그램. (PandaRank 가 쓰는 그 방식)

1왜 확장프로그램이어야 하나 (핵심)
웹사이트는 보안상 “남의 사이트(네이버)”랑 “내 PC 파일”을 못 만져요. 그 벽을 넘는 건 확장프로그램뿐이라, 자동 발행엔 확장이 반드시 필요해요.
🚫 웹사이트(우리 si0in.kr)가 못 하는 것
• 네이버 글쓰기 화면을 조작(글·사진 넣기)
• 내 PC에 다운받은 파일 읽기
• 다른 사이트(네이버)에 사진 업로드
→ 브라우저가 보안으로 막아둠
✅ 확장프로그램은 할 수 있는 것
• 네이버 에디터 페이지에 코드 주입 → 글·사진 자동 입력
• 우리 서버에서 사진 받아 네이버에 자동 업로드
• 정한 순서/위치에 정확히 삽입
→ 그래서 PandaRank도 “확장 설치”
2확장이 없으면? (지금 = 전부 수동)

사진 9장짜리 후기 하나 올리려면 사용자가 직접:

  • 😮‍💨
    글 복사 → 사진 9장 다운로드 → 네이버 글쓰기 열고 → 글 붙여넣기 → 사진 하나하나 업로드하고 → [1][2] 자리에 일일이 배치.

확장 = 이 모든 걸 [네이버에 넣기] 버튼 한 번으로. 이게 “진짜 자동화”이자 우리만의 킬러 기능.

3동작 흐름 (사용자가 보는 것)
1
시공막내 웹에서 글 생성 + 사진 배치(부위 매칭·드래그·수정) — 지금 프로토 그대로.
2
네이버 블로그 글쓰기 창을 연다 (확장이 자동으로 열거나, 사용자가 열면 확장이 감지).
3
[네이버에 넣기] 클릭 → 확장이 글을 입력하고, 사진을 [1][2] 자리에 업로드·삽입.
4
사용자는 훑어보고 발행 버튼만. 끝.
4기술 뼈대 (개발용)
  • 🧩
    확장 구성 — content script(네이버 에디터 페이지 주입) + background + popup. Manifest V3.
  • 🔗
    웹↔확장 통신 — 우리 웹 [넣기] → 확장으로 데이터 전달(window.postMessage or externally_connectable). 데이터 = 글(서식·사진 마커) + 사진 목록.
  • 🖼️
    사진 — 확장이 우리 서버(owner 인증 토큰)에서 사진을 fetch → 네이버 에디터의 이미지 업로드 흐름에 주입(파일 input / 드래그 / 클립보드 중 되는 방식).
  • ✍️
    네이버 SmartEditor 자동화 — 에디터 DOM에 텍스트(볼드·인용구 서식 포함) 입력 + 사진을 마커 위치에 삽입.
  • 🔐
    인증 — 확장 ↔ 우리 웹 세션 연동(사진 받으려면 로그인된 owner 확인).
5난이도 · 리스크 (솔직히)
높음
네이버 SmartEditor 자동화 — 구조가 복잡하고 수시로 바뀜. 네이버가 에디터 바꾸면 확장이 깨질 수 있어 유지보수가 계속 필요. (가장 큰 리스크)
중간
사진 정확한 위치 삽입 — [1][2] 자리에 정밀히 넣으려면 에디터 커서/DOM 조작 필요.
중간
네이버 정책 — 자동화 감지 주의(과도한 자동 발행은 위험). “초안까지만, 발행은 사람이” 로 안전하게.
중간
크롬 웹스토어 심사 + 배포 — 등록·검수 절차 + 설치 안내(사장님 스샷의 PandaRank처럼).
6단계별 개발 (작게 시작해서 키우기)
MVP 가장 빠름
글 텍스트만 네이버 에디터에 자동 입력(볼드·인용구 포함). 사진은 번호순 다운로드로 사용자가 넣기. — 확장의 절반 가치를 빠르게.
2단계 사진 자동
사진을 확장이 네이버에 자동 업로드 + 대략 위치에 삽입.
3단계 정밀
[1][2] 정확한 위치 매칭 + 서식 완성도 + 인스타/스레드는 복사만(자동 발행 API 없음).
결론: 확장은 “우리 웹에서 만든 글+사진을 네이버에 원클릭으로 꽂는 마지막 구간”을 위해 필요해요(웹만으론 물리적으로 불가). 리스크는 네이버 에디터가 자주 바뀌는 것 → MVP(글만 자동)로 작게 시작해서 반응 보고 사진 자동까지.

이 방향·단계 괜찮으면 → 다음은 MVP 확장 실제 개발로 들어가면 돼요. (별도 프로젝트로 잡아서)
