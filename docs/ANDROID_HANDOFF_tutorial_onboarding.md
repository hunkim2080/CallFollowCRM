## 0. 컨셉 (사장님 설계)

- 앱 처음 진입 → "지금부터 튜토리얼을 시작해볼게요! 이 어플은 이렇게 운영해요!"
- **재생버튼을 누르면 애니메이션이 실행되는 구조.**
- 사용자는 구경만 함 — 클릭은 전부 앱이 대신 (가짜 데이터 애니메이션).
  이유: 40~50대 사장님들 "잘못 누르면 어쩌지" 공포 제거.

---

## 1. 시나리오 1 — 전화 한 통이 일정까지 (사장님 확정)

순서 그대로:

1. **고객한테 전화가 와요.** — 가짜 전화가 옴.
2. 가짜 고객정보로 **주소와 최근대화기록까지 보이는 팝업창** 노출.
   → ⭐ 감탄 포인트 ① (여기서 일시정지, §3-1)
   → 구현: 이번에 만든 **전화 미리보기 오버레이 재활용** (CallStateReceiver 쪽 UI 그대로, 데이터만 가짜).
3. 전화를 받고 1초만에 끊어지는 애니메이션.
4. 그 고객과 챗스크린 → **통화요약이 쭈르륵** 되어 있음.
   → ⭐ 감탄 포인트 ②
5. 그 고객에게 접수서를 보냄. **클릭은 앱이 대신 함** (이런 게 있다 정도만 보여줌).
   문구: "고객에게 접수서를 발송해요!"
6. 고객이 접수서 작성 완료 → 챗스크린에 **접수서 작성 완료 메시지**가 올라옴.
7. 고객 상세보기 클릭됨 → **시공일정과 금액이 자동으로 등록**되어 있음.
8. 일정탭 클릭 → 고객이 등록한 일정 클릭 → **그 고객이 등록되어 있는 모습**.
   → ⭐ 감탄 포인트 ③

## 2. 시나리오 2 — 대화가 편해져요 (사장님 확정)

1. 고객이 문자로 문의 → 클릭해서 챗스크린 접속.
2. **미리 준비된 답변(추천답변) 하나 클릭해서 발송.**
3. 다시 답장이 오면 → 답장을 직접 타이핑하다가 **다듬기 버튼 클릭 모션** → 글이 예쁘게 다듬어짐 → 발송.
   문구: "고객과의 대화가 편해져요!"

## 3. 보완 원칙 (cowork 제안 · 사장님 승인)

1. **감탄 포인트 3곳에서만 일시정지** + "다음 →" 탭 대기. 나머지 장면은 자동재생.
   (자동으로 쭉 흘러가면 감탄할 틈이 없음.)
2. **길이: 시나리오당 40~60초.** 장면당 3~5초. 어디서든 "건너뛰기" 가능.
3. **끝나고 "진짜 한 번" 연결:**
   - 시나리오1 끝 → "이제 사장님 번호로 접수서를 진짜 보내볼까요?" 버튼 (본인 번호로 접수서 발송 = 고객 입장 체험).
   - 시나리오2 끝 → "통화녹음 연결하기" 버튼 (자동찾기 화면으로).
   - 구경(시나리오) → 체험(딱 1개) 세트. 강요 X — 버튼일 뿐, 스킵 가능.
4. **더보기 탭에 "사용법 다시보기"** 메뉴 → 튜토리얼 재실행.

디테일:
- 시나리오2 다듬기 장면은 **before/after 를 크게 대비** (투박한 문장 → 예쁜 문장이 그 기능의 전부).
- 튜토리얼 중 실제 SMS/서버 호출 절대 발생 금지 — 전부 가짜 데이터 + 로컬 애니메이션.
- 가짜 고객 데이터는 튜토리얼 종료 후 DB 에 남지 않게.
