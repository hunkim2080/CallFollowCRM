## 핵심 두 축 (이 자료가 끝나는 시점에 투자자 머리에 남길 것)

1. **Network Effect** — 1인 시공 사장은 혼자 일할 수 없다. 시공막내는 사장-사장을 연결한다. 사용자가 늘수록 가치가 증가하는 양면 시장.
2. **AI 기술력** — Whisper STT(자체 호스팅, 청크 병렬) + Gemini→Haiku 라우팅 + RAG(사장님 톤 학습) + 화자 구분 요약. 단순 챗봇 아님.

## 톤 가이드
- 한 슬라이드 한 메시지. 큰 제목, 짧은 본문.
- 숫자가 있으면 한복판에 굵게.

# Slide 3 — 페인 (왜 이 시장인가)

**제목**: 줄눈 사장님의 하루

> 오전 7시. 신축 아파트로 출발하면서, 운전 중에 카톡 3개·전화 2통.
> 한 손엔 운전대, 한 손엔 폰. 답장 미루면 다른 사장에게 일이 갑니다.
> 현장 도착, 줄눈 4시간. 끝나면 견적 문의 7개가 쌓여있어요.
> 누가 진지하고 누가 가격만 떠보는 건지, 다시 통화 다 들어봐야 압니다.

**오른쪽 박스 (페인 리스트)**:
- 메시지 응답 지연 → 고객 이탈
- 통화 내용 못 외움 → 약속 누락
- 큰 현장 = 혼자는 불가능 → 거절
- 일당 사장 모집 → 매번 단톡방 도배
- 정산·계좌·일당 = 종이 메모

**비주얼**: 시공 현장 사진 + 카톡 알림 아이콘 다중 겹침.

# Slide 6 — 솔루션 #2: 협업 사장 (Network)

**제목**: 큰 현장? 동네 사장에게 협업 요청

> 강동 신축 아파트 욕실 4세대, 혼자는 못 합니다.
> 시공막내가 같은 동네 줄눈 사장에게 협업 요청을 보냅니다.
> 일당 25만 원 합의 → 출동 2시간 전 자동 알림 → 3km 지점 자동 도착 알림 → 끝나면 계좌로 즉시 정산.

**흐름 다이어그램**:
```
A 사장 [현장 발견]
   ↓ (협업 요청 + 일당)
B 사장 [수락]
   ↓
[자동 출동 알림 2h 전]
   ↓
[3km 자동 도착 푸시]
   ↓
[현장 사진·증거 공유 — 분쟁 보호]
   ↓
[A 사장 계좌 입금 → B 영구 이력 적립]
```

**비주얼**: 사장 A — 사장 B 양쪽 폰 목업 + 푸시 알림.

# Slide 7 — 솔루션 #3: 일당 모집 (Marketplace)

**제목**: "이번 주 토요일, 일당 사장님 4명 찾아요"

> A 사장이 모집 공고 작성 (날짜 / 대략 위치 / 일비) → 등록된 동네 사장 N명에게 일괄 푸시.
> 선착순 지원 — 1·2·3등 순서대로 보임.
> A 사장이 지원자별 "함께한 적 7번, 받은 일당 175만 원" 가산점 보고 선택.
> 선택 즉시 정확한 주소 공개 + 협업 현장 자동 확정.

**비주얼**: 모집 공고 카드 + 지원자 순위 리스트 (모자이크 처리).

**핵심 메시지 (오른쪽 박스)**:
- 주소 비공개 (확정 전) — 개인정보 보호
- 지원자끼리 서로 안 보임
- 과거 거래 이력 = 신뢰 신호

# Slide 9 — Network Effect (핵심 ⭐)

**제목**: 사장이 늘수록, 모두에게 더 큰 가치

**다이어그램** (반드시 시각화 — 가장 중요한 슬라이드 중 하나):

```
사장 1명 → 솔로 AI 비서 (가치 X)
사장 10명 → 협업 가능 (가치 ↑)
사장 100명 → 일당 모집 가능 (양면 시장 ↑↑)
사장 1,000명 → 동네별 즉시 매칭 (가치 폭발)
```

**3축 설명**:
- **수평 협업** — 사장 ↔ 사장 (같은 직종, 큰 현장 분담)
- **수직 협업** — 사장 → 일당 사장 (작은 일감 분배)
- **이력 자본** — 함께 일한 횟수·정산 이력이 그 자체로 사용자 락인

**비주얼**: 노드 그래프 — 사장 노드가 늘어날수록 엣지(연결) 폭발적으로 증가하는 애니메이션 또는 4단계 정적 컷.

# Slide 10 — 기술 차별점 ⭐

**제목**: 단순 챗봇이 아닙니다

**4개 기술 박스**:

🎙️ **Whisper STT 자체 호스팅 + 청크 병렬**
30분 통화도 1분 안에 텍스트 변환. CPU 추론 + ffmpeg 청크 분할 + 비동기 병렬.
서버 비용 = 일반 클라우드 STT의 1/10.

🧠 **LLM 모델 라우팅 (Gemini → Haiku)**
1차 Gemini 2.5 Flash (저비용·빠름) → 실패 시 Claude Haiku fallback.
품질은 유지, 비용은 절반. 사용량 모니터링·자동 분기.

🎯 **RAG 톤 학습 (bge-m3 + sqlite-vec)**
사장님 과거 메시지에서 톤 코퍼스 자동 추출 → 답장 추천 시 그 톤으로 생성.
"내가 쓴 거 같다" 가 핵심 KPI.

🗣️ **화자 구분 통화 요약**
프롬프트 엔지니어링 + Q&A 흐름 강제 → 고객 발화와 사장 발화를 정확히 분리.
"우리 사무실 어디예요?" → 🙋 고객 / "수원이요" → 🏢 사장님.

**비주얼**: 기술 스택 다이어그램 (입력 → 처리 → 출력).
