# RING-GO — UI/UX 재설계 공모 명세서

> 1인 시공자 (줄눈 / 인테리어) 를 위한 AI 통화·문자 후속 처리 CRM.
> 현재 안드로이드 네이티브 (Kotlin + Jetpack Compose) 로 동작 중.
> **본 명세서를 읽고 새 UI/UX 를 제안하는 것이 임무.**

---

## 0. 한 줄 요약

**"통화 끊자마자 AI 가 다음 액션 카드를 띄워주는 시공자 전용 CRM."**
사장님이 잊지 않게 잡아주고, 답장은 사장님 톤으로 자동 작성. 메시지 답·일정·입금까지 한 화면에서.

## 1. 사용자 페르소나

**이름**: 디테일라인 사장님 (가명 junjun)
**나이**: 30대 후반 ~ 50대
**직업**: 1인 줄눈 시공자 (욕실/주방 줄눈 보수). 같은 카테고리: 인테리어 도장, 누수 보수, 마루 시공 등 **1인 운영 시공 전문가**.
**기기**: 갤럭시 S9 (Android 10, 화면 360×740 dp, OLED). 일부는 S23/S24.
**언어**: 한국어 (반말/존댓말 혼용 친근 톤).
**기술 수준**: 안드로이드 잘 씀, 갤메시지/에이닷 활용. 개발 X.

### 사장님 하루 (시나리오)
- 아침: 전 날 받은 미확인 통화/문자 정리 (5~10건)
- 낮: 현장 시공 (욕실에서 무릎 꿇고 + 손에 줄눈재 묻음) 중간중간 문의 전화 받음 (2~5건)
- 차 이동 중: 운전 + 음성으로 답장 (에이닷 연동)
- 저녁: 견적 답장 / 시공 일정 잡기 / 잔금 받기 / 후기 요청
- 밤: 이튿날 시공 일정 다시 확인

### 사장님 통점 (실제로 듣고 정리)
1. **"통화 끝나면 누가 누군지 까먹어"** — 통화 직후 메모/답장 안 하면 새로운 통화 5건 후 무엇이 누구인지 헷갈림.
2. **"답장 쓰는 데 시간 너무 걸려"** — 견적 답장 한 통 쓰는데 3~5분. 하루 20건이면 1시간.
3. **"미확인 후속 까먹음"** — 같은 사람에게 두 번 전화 왔는데 첫 통화 답장 안 한 거 모르고 또 받음.
4. **"손이 거칠어서 버튼 작은 거 못 누름"** — 시공 후 손가락 굵음 + 줄눈재 묻음.
5. **"잔금/계약금 헷갈림"** — 누가 얼마 입금했는지 별도 메모장 관리.
6. **"현장 주소 매번 다시 물음"** — 고객이 전에 보낸 주소 다시 찾기 귀찮음.
7. **"카테고리 자동 분류 안 되면 다 섞여 보임"** — 시공 대기/완료/단순 문의가 한 리스트에 섞임.

## 2. 핵심 가치 제안

**기존 앱 (갤메시지/카카오톡)** : 메시지 송수신만. 시공자에게 필요한 후속 처리 X.

**RING-GO** : 통화/문자 받은 후 **AI 가 다음 액션을 손에 쥐어줌** :
1. 통화 끝 → 자동 카드 (메모 + 자동 답장 + 빠른 액션)
2. 문자 받음 → AI 가 **상담 전략 3개** 제안 (단순 "답변 3개" 가 아닌 "어떤 의도로 어떻게 대화 전환할지")
3. 같은 사람 두 번째 통화 → 첫 답장 안 했으면 "조용한 알림" 으로 잊지 말라고 옆구리 찌름
4. 입금 받으면 자동으로 카테고리 "시공 완료" 로 승격
5. 사장님 톤 학습 → 시간 지날수록 답장이 사장님처럼 자연스러워짐

**핵심 차별화** : "메시지 앱" 이 아니라 **"세일즈 운영 OS"**. 사장님의 머릿속을 외부에 박아둠.

## 3. 사용 환경 / 제약

| 항목 | 제약 |
|---|---|
| **기기 화면** | 갤S9 = 360×740 dp (현대 안드 폰 중 좁은 편). 모든 디자인 이 사이즈에서 안 깨져야 함 |
| **사용 환경** | 실내(욕실, 어두움) + 실외(현장 햇빛) + 차 안(야간) + 침대 위(밤) |
| **터치 정확도** | 손가락 굵음 + 줄눈재 묻음 → **모든 핵심 액션 버튼 최소 48dp** |
| **언어** | 한국어 only. 한글 폰트 가독성 매우 중요 (Pretendard 적용 중) |
| **인터넷** | 시공 현장 = 4G/5G OK. 가끔 약함. **오프라인 안전** 필수 (DB local) |
| **권한** | SMS 송수신, 전화 상태, 통화기록, 연락처, 알림, 오버레이 (PostCallCard 용) |
| **배터리** | 시공 중 폰 손에 못 듦. 알림 안 놓침 보장 (백그라운드 안정성) |
| **개발 환경** | Kotlin + Jetpack Compose (Material3) + Room. **재구현 가능한 형태로 제안 환영** |

## 4. 핵심 기능 12개 (자세히)

### F1. PostCallCard — 통화 직후 자동 오버레이
- **트리거**: 통화 종료 (CallLog 기록 직후 1.5초)
- **표시**: 화면 위에 카드 띄움 (SYSTEM_ALERT_WINDOW 권한 필요)
- **내용**:
  - 전화번호 / 통화 종류 (수신/발신/부재중)
  - 메모 입력 칸
  - 자동 답장 카운트다운 (10초 후 발송) + 취소 버튼
  - 사장님이 미리 등록한 빠른 답장 템플릿 3개
- **현재 문제**: 운전 중에 안 보임 / 작은 화면에 카드 큼 / 자동 답장 무서워서 못 켬

### F2. AI 추천 답변 = 상담 전략 3개
- 문자 받으면 AI 가 3가지 다른 "상담 전략" 제안 (단순 paraphrase 아님)
- 각 전략 = **시나리오 (예: "견적 문의") × 의도 (예: "신뢰 구축")** 의 조합
- 예시:
  ```
  고객 메시지: "줄눈 시공 한 평에 얼마예요?"
  
  AI 추천 답변 (3개):
  1️⃣ [가격 직접 안내] "한 평당 12만원이에요. 욕실 사이즈 알려주시면 정확한 견적..."
  2️⃣ [신뢰 구축 우선] "안녕하세요. 줄눈 전문 디테일라인입니다. 욕실 사진 한 장만 보내주시면..."
  3️⃣ [현장 방문 유도] "정확한 견적은 현장 방문 후 가능합니다. 5/30 오후 방문 가능하세요?"
  ```
- 사장님이 한 탭 → 즉시 발송 OR 편집 → 발송
- **사장님 톤 학습**: 사장님 옛 메시지 50개 분석 → 사장님 어투로 다시 작성

### F3. 고객 페르소나 (RAG 기반)
- 누적 대화 20건 이상이면 AI 가 고객 "성격" 자동 분석
- 예: "이 고객은 34평 구축 주택의 거실 화장실 바닥 줄눈 시공을 원하며, 소요시간·비용·가능한 빠른 일정을 문의 중인 상태. 처음에는 신축 욕조 화장실 시공을 문의했다가 변경된 요청으로 보인다."
- CustomerDetailScreen 에 카드로 표시

### F4. 자동 카테고리 분류
- 사장님 정의 카테고리: "시공 대기 🔨" / "시공 완료 ✅" / "단순 문의" 등
- 자동 분류 룰:
  - 계약금 입금 → "시공 대기"
  - 잔금 입금 → "시공 완료"
  - 사장님이 직접 분류한 고객은 자동 분류 X (수동 우선)

### F5. 미확인 후속 처리 (swipe)
- HomeScreen 에서 미확인 통화/문자 = 빨간 점 표시
- 사장님이 처리하면 → 오른쪽 swipe → "확인함" 표시
- 같은 번호 두 번째 통화 시: 첫 통화 답장/분류 안 했으면 **조용한 알림** (헤드업 X, 알림함만)

### F6. 시공 일정 관리
- 캘린더 화면 + 고객별 시공일 등록
- D-1 알림 (시공 전 날 "내일 [고객] 시공이에요" — Phase B 예정)
- 시공일 등록 = "상황 종료" → 다음 통화 후속 알림 OFF (사장님 결정)

### F7. 잔금 자동 계산
- 고객 카드에 [총금액 / 계약금 / 잔금] 표시
- **잔금 = 총금액 − 계약금** 자동 (사장님 직접 입력은 우선)
- 계약금 받으면 자동으로 "시공 대기" 카테고리, 잔금 받으면 "시공 완료"

### F8. 자동 MMS 묶음
- 사장님이 사진 5장 보내면 갤메시지에선 5건의 MMS. RING-GO 는 **1개 묶음** 으로 표시 (UX 명확성)
- 사진 클릭 시 풀스크린 뷰어 + 스와이프

### F9. 고객 상세 + 인라인 채팅
- 고객 카드 펼치면 즉시 채팅 가능 (별도 ChatScreen 안 들어가도 됨)
- 메모 + 입금 카드 + 페르소나 + 주소 + 첨부 사진 한 화면

### F10. 갤메시지 식 카테고리 칩
- HomeScreen 상단에 카테고리 필터 칩 (전체 / 미확인 / 오늘 신규 / 완료 / 시공전 / ...)
- 사장님이 직접 카테고리 만들고 이모지 박음

### F11. AI ✨ 다듬기
- 사장님이 답장 쓰다가 ✨ 버튼 → AI 가 톤/오타/매끄러움 보강
- Gemini 2.5 Flash 사용 (서버 거침)

### F12. 톤 학습 (sajangnim's voice RAG)
- 사장님 보낸 메시지 50개 → 임베딩 (bge-m3) → 검색 가능 형태로 저장
- 새 답장 생성 시 비슷한 상황의 옛 답장 5개를 참조 → 사장님 톤 유지

## 5. 주요 화면 (현재 구조)

### 5.1 HomeScreen — 타임라인 + 필터
- **상단**: 로고 ("RING-GO") + 서버 상태 도트 + [📅 일정] [📝 템플릿] [⚙️ 설정] 아이콘
- **필터 칩 row**: [전체] [미확인 ⚠️] [오늘 신규 🆕] [완료] [시공전] [+ 사용자 정의]
- **KPI 카드 3개** (옵션): 오늘 신규 / 미확인 / 이번주 시공 — 클릭 시 필터 적용
- **타임라인** (LazyColumn):
  - 날짜 그룹 헤더 ("5. 28. 수요일")
  - 카드: [통화 종류 아이콘] [번호 또는 고객명] [AI 요약 한 줄 ✨] [시간 · 처리 상태]
  - 미확인 카드: 빨간 점
  - 시공 일정 등록된 카드: 작은 [완료] 뱃지
  - 카드 우 swipe → "확인함"
- **FAB**: [+ 수동 입력] — 직접 번호 타이핑해서 새 고객 추가
- **하단**: 시스템 네비게이션 (홈/뒤로/최근)

### 5.2 ChatScreen — 메시지 + AI 추천 답변
- **상단**: ← 뒤로 + 별표 메시지 + 📞 전화 + 영상통화 + ⋮ 메뉴
- **요약 카드** (접을 수 있음): "✨ 대화 요약 5/28 14:52 까지 · 신축 욕조 화장실 바닥 40만원 견적 안내 완료 + 다음 액션"
- **고객 페르소나 카드** (접을 수 있음): "🧠 고객 페르소나 5/29 06:39 · 이 고객은 34평..."
- **주고받은 문자 (24건) ▾** — 펼치면 메시지 버블
- **AI 추천 답변 3개** (Composer 위 가로 스크롤):
  - 칩 형태, 라벨 ("[1] 가격 직접 안내") + 내용 2줄 미리보기
  - 한 탭 = 즉시 발송 / 길게 누르면 편집
  - 오른쪽 ↻ 버튼 = 재생성
- **Composer** (하단):
  - 텍스트 입력 박스
  - 📷 사진 첨부 (48dp)
  - ✨ AI 다듬기 (48dp)
  - ▶ 전송 (52dp 둥근 파란 버튼)

### 5.3 CustomerDetailScreen — 고객 한 명 전체 정보
- **상단**: ← 고객 상세
- **이름 카드**: + 이름 추가 / 기존 이름 표시
- **현장 주소 카드**: 📍 [등록된 주소 or "아직 등록된 주소가 없어요"] + [+ 직접 등록] + [📍 길찾기]
- **대화 요약 카드** (5분 단위 갱신)
- **고객 페르소나 카드** (RAG)
- **시공 일정 카드**: 📅 [등록된 일정 or "+ 시공일 등록"]
- **입금 카드**: 총금액 / 계약금 / 잔금 (자동 계산 표시)
- **카테고리 칩**: [시공 대기 🔨] [시공 완료 ✅] 등 — 사장님이 박을 수 있음
- **첨부 사진** 갤러리 (썸네일 grid)
- **주고받은 문자 24건 ▾** (접힘 기본)
- **메모 영역**: 사장님 자유 메모
- **하단**: [💬 문자 보내기] 풀너비 버튼

### 5.4 ScheduleScreen — 시공 일정
- 월간 캘린더 + 그 날 시공할 고객 리스트
- D-day 라벨 (오늘 / D-1 / D-3 등)

### 5.5 SettingsScreen — 권한 / 자동응답 / 빠른 액션
- 권한 상태 (SMS, 전화, 알림, 오버레이) — ON/OFF
- 자동 답장 기본 켜기 / 끄기
- 첫 통화 자동 답장 템플릿 (수신용 / 부재중용)
- 빠른 액션 3슬롯 (알림에서 한 탭 발송)
- 기본 SMS 앱 전환 안내
- 톤 학습 업로드 동의 / 진행 상황

### 5.6 + 그 외 (간단)
- **FollowUpScreen**: 미확인 처리 대기 큐
- **TemplateListScreen / EditScreen**: 메시지 템플릿 CRUD
- **PricingItemsScreen**: 견적용 가격표 관리
- **AiMessageScreen**: AI 가 작성한 메시지 모음
- **StyleLearningScreen**: 톤 학습 진행 상황 + 업로드된 샘플 개수
- **OnboardingPermissionScreen**: 첫 진입 시 권한 + 기본 SMS 앱 전환 유도

## 6-0. ⚠️ 디자인 수준 (가장 중요)

**"개발자가 코딩하다 만든 UI" 가 아니라 "시니어 프로덕트 디자이너가 Figma 에서 며칠 고민해 만든 UI" 를 원합니다.**

지금 RING-GO 의 디자인은 솔직히 "개발자가 직접 깎은 토스 따라하기" 수준입니다. 사장님이 원하는 건:

### ✅ 반드시 충족
- **2025-2026 최신 모바일 디자인 트렌드** 적극 반영
- **시각적 위계 (Visual Hierarchy)** — 무엇이 가장 중요한지 한눈에 보임 (대비 / 크기 / 위치 / 색)
- **마이크로 인터랙션** — 카드 펼침 / 칩 탭 / 스와이프 마다 부드러운 모션 (CSS transition + transform)
- **타이포그래피로 말함** — 큰 숫자, 굵은 헤더, 가벼운 본문 — Pretendard 의 weight 위계를 적극 활용
- **공백 (Negative Space) 충분히** — 시공자가 한 손으로 스캔할 수 있는 여백
- **컬러 1~2개에 집중** — Primary + Accent 2개로 모든 UI 가 동작 (잡색 금지)
- **시각적 일관성** — 모든 카드의 모양/그림자/라운드/간격이 같은 시스템

### 🎨 벤치마크 (이 수준 또는 그 이상)

- **Linear** — 다크모드 + 타이포그래피 + 흰 글씨의 가독성
