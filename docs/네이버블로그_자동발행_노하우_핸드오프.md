# 네이버 블로그(스마트에디터 ONE) 자동 발행 — 노하우 & 코드 핸드오프

> 시공막내 웹에서 만든 글을 **네이버 블로그 글쓰기 창에 서식까지 그대로** 자동으로 넣는 방법.
> 공식 문서엔 없는 "함정"들이 핵심이라, 실제로 부딪혀 알아낸 것만 정리했습니다.
> (참고 원본: `extension/` — 크롬 확장 실제 구현체, `extension/format.js`, `extension/reference/`)

---

## 0. 한눈에 — 핵심 3가지

1. **네이버는 "가짜(합성) 입력"을 거부한다.** `dispatchEvent`로 만든 paste/click, `innerText` 주입, `getSelection().addRange()` 선택 → **전부 무시**. 오직 **브라우저가 진짜로 낸 키·클릭·클립보드**만 먹는다.
2. **서식 있는 본문**은 → **HTML을 클립보드에 담고 → 진짜 Ctrl+V**로 넣으면 통째로 들어간다 (소제목/인용구/구분선/볼드까지 네이버가 알아서 자기 구조로 변환).
3. **소제목만 단축키가 없다.** → 툴바 **'문단 서식' 드롭다운을 좌표로 진짜 클릭**해서 '소제목' 선택.

이 3개만 알면 나머지는 디테일입니다.

## 1. 구현 방법 두 가지 (둘 다 CDP 기반)

"진짜 입력"을 만들려면 결국 **CDP(Chrome DevTools Protocol)** 의 `Input.*` 명령을 써야 합니다. 접근 경로만 둘:

| | (A) 외부 자동화 | (B) 크롬 확장(MV3) |
|---|---|---|
| 방식 | Chrome을 `--remote-debugging-port=9222`로 띄우고 **Playwright** `chromium.connectOverCDP('http://127.0.0.1:9222')` 로 붙음 | 확장이 **`chrome.debugger`** API로 현재 탭에 CDP 붙음 |
| 로그인 | 사람이 **미리 로그인**해 둔 프로필에 붙음 (자동 로그인 금지) | 사용자 브라우저 그대로 |
| 배포 | 서버/PC에 Node + Playwright 설치 필요 | 크롬 확장 설치 한 번(개발자 모드 or 스토어) |
| 공통 | **둘 다** `Input.dispatchKeyEvent`(진짜 키) / `Input.dispatchMouseEvent`(진짜 클릭) / 클립보드 + Ctrl+V 로 동작 | ← 기법은 100% 동일 |

> 시공막내는 (B) 확장으로 배포합니다. 이유: 웹(브라우저)은 보안상 남의 사이트(네이버)·유저 PC를 못 만짐 → 확장만 가능. 확장의 content script도 "진짜 입력"은 못 내므로 **`chrome.debugger`(CDP)** 로 신뢰된 입력을 보냄.

## 2. 절대 원칙 (안전 — 반드시)

- **자동 발행 금지.** 코드에 '발행' 버튼 셀렉터를 두지 마세요. 클릭 직전 요소 텍스트에 "발행"이 있으면 **무조건 중단**하는 가드를 두고, 항상 **임시저장(Ctrl+Shift+S)** 까지만.
- **세션 만료**(로그인 페이지로 튐)면 자동 로그인 시도하지 말고 **사람에게 알리고 중단.**
- **자동 실행 중 브라우저를 건드리지 마세요.** 그 순간 마우스·키보드를 원격조종하는 거라, 유저가 클릭/타이핑하면 충돌해서 멈춥니다. (진행 중 안내 배너 필수)
- **F12(개발자도구) 닫기.** 열려 있으면 디버거가 겹쳐 실패("Another debugger already attached").

## 4. 킬러 기법 — 서식 붙여넣기 (클립보드 HTML + 진짜 Ctrl+V)

합성 paste 이벤트나 `innerText` 주입은 에디터가 **거부하거나 서식을 잃습니다.** 정답은 사람이 복붙하는 것과 완전히 동일하게:

**① 클립보드에 `text/html` + `text/plain` 두 flavor로 담고 → ② 본문 포커스 → ③ 진짜 Ctrl+V.**

```js
// ① 클립보드에 서식 HTML + 순수 텍스트 담기 (페이지/컨텐트 컨텍스트)
async function putClipboard(html, plain) {
  await navigator.clipboard.write([ new ClipboardItem({
    "text/html":  new Blob([html],  { type: "text/html" }),
    "text/plain": new Blob([plain], { type: "text/plain" }),
  })]);
}

// ③ CDP로 "진짜 Ctrl+V" (chrome.debugger 또는 playwright CDPSession의 send)
//    modifiers: 2 = Ctrl 눌린 상태. windowsVirtualKeyCode 17=Ctrl, 86=V.
async function realCtrlV(send) {
  await send("Input.dispatchKeyEvent", { type: "rawKeyDown", modifiers: 2, key: "Control", code: "ControlLeft", windowsVirtualKeyCode: 17, nativeVirtualKeyCode: 17 });
  await send("Input.dispatchKeyEvent", { type: "keyDown",   modifiers: 2, key: "v", code: "KeyV", windowsVirtualKeyCode: 86, nativeVirtualKeyCode: 86 });
  await send("Input.dispatchKeyEvent", { type: "keyUp",     modifiers: 2, key: "v", code: "KeyV", windowsVirtualKeyCode: 86, nativeVirtualKeyCode: 86 });
  await send("Input.dispatchKeyEvent", { type: "keyUp",     key: "Control", code: "ControlLeft", windowsVirtualKeyCode: 17, nativeVirtualKeyCode: 17 });
}
```

> **맥 외부 자동화**라면: `osascript`로 시스템 클립보드에 HTML flavor를 적재한 뒤 본문 클릭 → `Meta+KeyV`(진짜 ⌘V). 원리는 동일.
>
> **제목**은 서식이 없으니 클립보드 대신 제목란 진짜 클릭 후 `Input.insertText`로 바로 넣어도 됩니다.

## 5. 마커 → HTML 변환기 (그대로 써도 됩니다)

원고를 **마커 텍스트**(`## 소제목`, `> 인용`, `**굵게**`, `---` 구분선, 빈 줄=문단)로 두고, 붙여넣기 직전에 이 함수로 **스마트에디터가 먹는 HTML**로 변환합니다. (`extension/format.js` 전문)

```js
function escapeHtml(s){return String(s).replace(/&/g,"&amp;").replace(/</g,"&lt;").replace(/>/g,"&gt;").replace(/"/g,"&quot;");}
function boldEscape(seg){return escapeHtml(seg).replace(/\*\*(.+?)\*\*/g,"<b>$1</b>");}
function inlineHtml(s){                       // URL→<a>, **굵게**→<b>
  const urlRe=/(https?:\/\/[^\s<>()]+)/g; let html="",last=0,m;
  while((m=urlRe.exec(s))!==null){
    let url=m[1]; const trail=(url.match(/[.,!?)\]}'"]+$/)||[""])[0]; if(trail) url=url.slice(0,url.length-trail.length);
    html+=boldEscape(s.slice(last,m.index)); const eu=escapeHtml(url);
    html+='<a href="'+eu+'">'+eu+"</a>"; last=m.index+url.length;
  }
  html+=boldEscape(s.slice(last)); return html;
}
function toEditorHtml(draft){                  // 마커 원고 → 붙여넣기용 HTML
  const blocks=String(draft).replace(/\r\n/g,"\n").split(/\n{2,}/); const html=[];
  for(const block of blocks){
    const lines=block.split("\n").filter(l=>l.trim()!==""); if(!lines.length) continue;
    if(lines.every(l=>/^\s*>/.test(l))){       // 블록 전체 인용구
      html.push("<blockquote>"+lines.map(l=>inlineHtml(l.replace(/^\s*>\s?/,""))).join("<br>")+"</blockquote>"); continue;
    }
    for(const line of lines){
      if(/^\s*-{3,}\s*$/.test(line))       html.push("<hr>");
      else if(/^\s*#{1,3}\s+/.test(line))  html.push("<h3>"+inlineHtml(line.replace(/^\s*#{1,3}\s+/,""))+"</h3>");
      else if(/^\s*>/.test(line))          html.push("<blockquote>"+inlineHtml(line.replace(/^\s*>\s?/,""))+"</blockquote>");
      else                                 html.push("<p>"+inlineHtml(line)+"</p>");
    }
    html.push("<p><br></p>");                  // 문단 사이 빈 줄
  }
  return html.join("");
}
```

`text/plain` flavor(마커 제거한 순수 텍스트)도 같이 담으면 글자수·폴백에 안전합니다.

## 6. 함정 (여기가 진짜 핵심) 🔑

### 6-1. "프로그램으로 만든 선택 영역"은 무시된다
`window.getSelection().addRange(range)` 로 선택하고 굵게/서식을 걸면 **아무 일도 안 일어납니다**(카운트만 오르고 화면 그대로). 반드시 **실제 마우스**(`Input.dispatchMouseEvent`)나 **실제 클릭**으로 만든 선택/커서만 인정.

### 6-2. 블록 서식(소제목·인용구·본문)은 "문단 전체"에 적용
문단 단위 서식이라, 문단 안 한 글자만 선택해도 문단 전체가 바뀝니다. → **텍스트 선택 필요 없음.** 그 문단에 **진짜 커서만**(단일 클릭) 놓고 드롭다운에서 고르면 됩니다.

### 6-3. 굵게는 "선택"이 필요 — 커서만 있으면 문단 전체가 굵어짐 (함정!)
굵게는 인라인 서식이라 **선택 영역**에 적용. 커서만 둔 채 굵게를 누르면 **문단 전체**가 굵어집니다.
정답: **① 평범하게 타이핑 → ② 그 단어만 실제 마우스로 드래그 선택 → ③ 굵게(Ctrl+B).**

### 6-4. 소제목은 단축키가 없다 → 툴바 좌표 클릭
인용구(Ctrl+Alt+Q)·구분선(Ctrl+Alt+H)·굵게(Ctrl+B)는 단축키가 있지만 **소제목은 없음.** → **'문단 서식' 드롭다운 클릭 → '소제목' 옵션 클릭**(둘 다 좌표로 진짜 클릭). ※ 서식HTML을 `<h3>`로 붙여넣으면 소제목이 바로 되는 경우가 많아, 사실 킬러 기법(§4) 하나로 대부분 해결됩니다. 소급 적용이 필요할 때만 이 경로.

### 6-5. 인용구 블록엔 "출처 입력" 칸이 딸려 있다
인용구 만들고 내용 입력하면 커서가 인용구 안 + 아래 "출처 입력" 칸. 다음 작업으로 넘어가려면 **아래 방향키 두 번(ArrowDown ×2)** 으로 블록 탈출. ※ 툴바 "인용구 추가" 버튼은 **기존 문단을 바꾸는 게 아니라 빈 인용구를 새로 삽입**. 기존 텍스트를 인용구로 만들려면 **드롭다운의 "인용구"** 옵션.

### 6-6. 줄바꿈 걸친 문구 선택은 "박스 중앙 훑기"로 하면 깨진다
`getBoundingClientRect()`는 두 줄 문구를 하나의 큰 박스로 줌 → 세로 중앙 가로 훑기 = 엉뚱한 범위. **`range.getClientRects()`로 줄별 사각형**을 얻어 첫 줄 왼쪽(시작) → 마지막 줄 오른쪽(끝)으로 드래그(사람이 여러 줄 드래그하듯).

### 6-7. (맥) Home 키가 선택 해제·줄 맨앞 이동이 안 된다
맥에선 `Home`이 선택을 안 풀어서 이어지는 Delete가 본문까지 먹음. 줄 맨앞은 **`Meta+ArrowLeft`(Cmd+←)**. 커서만 두려면 트리플클릭 말고 **단일 클릭**.

### 6-8. 다른 기기(모바일)에서 저장한 글 불러오기
새 글 열 때 뜨는 "이어서 작성?" 팝업은 **그 브라우저 로컬 자동저장**이라 모바일 저장 글엔 안 뜰 수 있음. 대신 상단 **"임시저장된 글 보기"(카운트) 버튼** → 서버 저장함 목록 → **제목 일치 항목** 클릭. (항목 텍스트 앞 `[제목]` 딱지 + 뒤 날짜 떼고 매칭)

## 8. CDP 코드 스니펫 (진짜 입력 만들기)

```js
// 진짜 클릭 — 좌표(x,y)에. 셀렉터 좌표는 Runtime.evaluate 로 getBoundingClientRect 중심을 구함(iframe 오프셋 더하기).
async function realClick(send, x, y) {
  await send("Input.dispatchMouseEvent", { type: "mousePressed",  x, y, button: "left", clickCount: 1 });
  await send("Input.dispatchMouseEvent", { type: "mouseReleased", x, y, button: "left", clickCount: 1 });
}

// 셀렉터 → 화면 좌표 (iframe#mainFrame 안이면 프레임 offset 더함)
async function coordOf(send, selector) {
  const { result } = await send("Runtime.evaluate", { returnByValue: true, expression: `(() => {
    const fr = document.querySelector('#mainFrame');
    const doc = fr ? fr.contentDocument : document;
    const off = fr ? fr.getBoundingClientRect() : { left: 0, top: 0 };
    const el = doc.querySelector(${JSON.stringify(selector)});
    if (!el) return null;
    const r = el.getBoundingClientRect();
    return { x: Math.round(off.left + r.left + r.width/2), y: Math.round(off.top + r.top + r.height/2) };
  })()` });
  return result.value;   // {x, y} or null
}

// 텍스트 직접 입력(제목 등 서식 없는 곳) — 포커스 후
async function typeText(send, text) { await send("Input.insertText", { text }); }
```

> 텍스트로 요소를 찾을 땐 `querySelectorAll('button,[role="button"]')` 를 순회하며 `el.textContent` 매칭(해시 클래스 회피). 소제목처럼 컨테이너와 옵션 버튼이 겹칠 땐 **텍스트 길이가 짧은 실제 옵션 버튼**을 고르세요.

## 9. 안정성 / 봇 탐지 / 타임아웃

- **퇴고 체류**: 저장 "전"에 60~150초 사람이 훑어보는 시간(커서 곡선 이동·읽는 속도 스크롤 흉내). 붙여넣기 자체는 사람도 흔히 해서 숨길 필요 없지만, "에디터 열림 → 저장"의 **시간 간격·분량**이 서버가 보는 신호.
- **무한루프 방어**: 마커 순회 시 **같은 마커가 두 번 연속 잡히면(=진행 안 됨) 강제로 지우고 넘김.** 안 그러면 무한 반복 + 헛타이핑.
- **하드 타임아웃**(예: 2분): 각 문단 작업 "시작 전" 시간 체크 → 넘으면 바로 저장 단계로.

|---|---|
| `manifest.json` | 확장 설정 (MV3, `debugger` 권한) |

| `background.js` | `chrome.debugger` 자동 엔진 (제목·본문·소제목·사진·저장) — §4·§8 실제 구현 |
| `format.js` | 마커(##·>·**·---) → 스마트에디터 HTML (§5 전문) |
| `reference/네이버블로그_자동화_노하우.md` | Playwright/CDP 외부 자동화 버전 노하우 |
