# Play Console 「데이터 보안」 폼 답안지 (2026-07-05)

코드 실측 기준(api.si0in.kr 로 실제 전송되는 데이터). **거짓 없이 정확히** 채우는 게 목적.
핵심 원리: **서버 = 우리(사장님) 서버 → "수집(Collected)=예, 제3자 공유(Shared)=아니오"**.
(제3자 공유 = 광고회사·분석SDK 같은 남의 회사에 넘기는 것. 우리 서버로 보내는 건 "수집"임.)

---

## 1단계: 개요 질문
- **이 앱이 사용자 데이터를 수집/공유하나요?** → **예**
- **전송 중 데이터가 암호화되나요?** → **예** (전부 HTTPS)
- **사용자가 데이터 삭제를 요청할 수 있나요?** → **예** (개인정보처리방침 si0in.kr/privacy 에 삭제 경로 명시 필요 — 없으면 "아니오")

## 2단계: 수집하는 데이터 유형 — 아래 항목에 체크
각 항목 공통값: **수집=예 / 공유=아니오 / 일시적처리=아니오 / 필수 / 목적=앱 기능**

| 큰 분류 | 세부 항목 | 왜(근거) |
|---|---|---|
| 개인 정보 | **이름** | 고객 이름 전송 (통화요약·AI답변) |
| 개인 정보 | **전화번호** | 본인+고객 번호 (거의 모든 API) ← 구글이 콕 집은 것 |
| 개인 정보 | **주소** | 고객 주소·사업장 주소 (견적서·현장) |
| 금융 정보 | **기타 금융 정보** | 협업 정산용 입금 계좌(은행·계좌번호) 전달 |
| 메시지 | **SMS 또는 MMS** | 문자 내용 전송 (AI 답변·말투 학습) |
| 메시지 | **기타 인앱 메시지** | 채팅/대화 이력 전송 |
| 사진 및 동영상 | **사진** | 현장/증거 사진 서버 업로드(협업 공유) |
| 오디오 | **음성 또는 사운드 녹음** | 통화 녹음 파일 업로드(통화요약) |
| 앱 활동 | **기타 작업** | 시공일정·메모 등 (선택 — 넣으면 더 정확) |
| 기기 또는 기타 ID | **기기 또는 기타 ID** | FCM 푸시 토큰·기기 ID |

> 위치(GPS): **선언 안 함.** 지오펜스(현장 반경)는 폰 안에서만 처리하고 좌표를 서버로 안 보냄. → "수집" 아님.

## 3단계: 각 유형별 상세 (위 표 항목마다 동일하게)
- **수집됨(Collected)**: ✅ 예
- **공유됨(Shared)**: ❌ 아니오 (우리 서버로만)
- **일시적으로만 처리**: ❌ 아니오 (서버 저장)
- **필수/선택**: **필수** (핵심 기능)
- **수집 목적**: **앱 기능(App functionality)** 체크
  - (말투 학습 관련 = 오디오/메시지엔 "개인 맞춤설정"도 추가로 체크 가능. 없어도 무방)

---

## 주의 / 결정 필요
1. **삭제 요청 경로**: si0in.kr/privacy 에 "데이터 삭제 요청 방법(이메일 등)" 문구가 있어야 "예" 선택 가능.
   없으면 (a) 처리방침에 한 줄 추가하거나 (b) 일단 "아니오"로. → 사장님/서버(cowork) 확인.
2. **개인정보처리방침**과 이 신고서가 **일치**해야 함 (통화녹음·문자내용·계좌 수집을 방침에도 적어야).
3. 통화녹음·문자내용 수집은 구글이 가장 엄격히 보는 부분 → ①번 권한 선언서와 세트로 정확해야.
