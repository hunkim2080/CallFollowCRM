# 시공막내 — 무료/유료 모델 설계 (Draft, 2026-06-29)

> 사장님과 cowork 의 대화 정리. 결정한 것 + 결정 안 한 것 + 다음 단계.
> 사장님이 집중 가능할 때 다시 꺼내서 마저 검토 → 박기.

---

## 1. 비용 통제 필요한 이유

- Gemini API 429 (quota 초과) 진단 후 발견.
- 무료 사용자 = 매월 폭주 가능. 비용 예측 불가.
- 1인 시공자 = 일 30-50회 ↻ 누름. 베타 50명 × 일 50회 = 일 2,500건.
- Sonnet: 일 $7-12 (월 $200-360) / Gemini paid: 일 $0.75 (월 $22)
- **베타는 감당 가능. 정식 출시 1,000명+ 되면 거덜.**

## 2. 결정한 것 (사장님 OK)

### 한도 (정식 출시 시)
| 기능 | 무료 | 유료 |
|---|---|---|
| 추천답변 | **월 10건 + 시공일 충전 (cap 50)** | **무제한** |
| 통화요약 (텍스트) | 무제한 | 무제한 |
| 통화녹음 | **5분 cap** | **30분 cap** ← Whisper STT CPU 보호 |
| refine, infer-principle | 그대로 (한도 X) | 그대로 |

### 시공일 등록 → 추천답변 +1 충전 (사장님 천재 통찰)
- 시공일 1건 등록 = 추천답변 한도 +1건
- 월 cap 50건 (악용 방지)
- 익월 리셋
- = 사장님 KPI (캘린더 등록) 자동 ↑ + 사용자 충성도 ↑

### 단위 정의
- **1번 호출 (3개 후보 묶음) = 1회 차감**
- 3개 = UX 옵션. 비즈니스 단위는 1.

### 차감 표시 위치
- ↻ 버튼 옆 작은 카운트 "7/10"
- 한도 도달 시 모달 (upsell)

### 베타 사장님 처리
- **베타 = 무제한 (env BETA_UNLIMITED=1)**
- 한도 코드는 박지만 OFF
- 정식 출시 시 켜기

## 3. 유료의 진짜 본질 = "AI 가 대신함"

cowork 가 처음 제시한 차별화 (인사이트 보고서, 우선처리, 카톡지원, 톤학습) =
사장님이 평가: **다 가짜 가치**.
- 인사이트 보고서 = 40-50대 사장님 "이거 봐서 뭐해"
- 우선처리/카톡지원 = 없는 기능
- 톤학습 = 초심자 가치 인지 X

**사장님 본질** = "**일을 줄여줘**". 자동화.

### 진짜 유료 hook (정식 상용화 시)

**🔥 자동 답장 (Auto-reply) — 옵트인 패턴**
- 같은 패턴 답장 3번+ → 90% 유사도 검출
- "이런 문의 오면 자동 답할까요?" 모달
- 사장님 승인 시만 작동, 언제든 OFF
- 학습 충분 후만 작동 (고도화 필요)

**🔥 부재중 자동회신**
- 부재중 후 1분 안에 자동 문자
- "통화 중이라 못 받았어요. 평수 알려주시면 견적 미리 준비할게요"
- 놓친 콜 잡음 = 매출 직결 (한 건 30-80만원)

### 무료에 풀어도 OK (사장님 판단)
- **시공일 D-1 자동 알림** — 사장님이 직접 보내던 거. 무료 풀기.
- **시공완료 → 결제 요청 자동** — 대단한 느낌 X. 무료 풀기.

## 4. 가격

- 사장님 가설 = **월 5만원**
- 사장님 논리: "일당 50만원 1인 시공자한테 5만원은 아무것도 아냐"
- 매출 +100만원 ↑ 가능하면 ROI 20배
- 결정은 사장님이. 결제 시스템은 별도 cycle.

## 5. 이번 cycle 박을 거 (사장님이 미룸 — 다음에)

### 서버 측 (cowork)
1. 한도 시스템 (subscribers.plan_tier 기반, 베타 = 무제한)
2. 시공일 등록 → 추천답변 +1 충전 (월 cap 50)
3. 응답에 remaining_this_month, monthly_limit 필드
4. 통화녹음 길이 제한 (free 5분 / pro 30분)

### 안드로이드 핸드오프 (cowork 가 prompt 작성)
1. ↻ 옆 카운트 "7/10" 표시
2. 시공일 등록 후 토스트 "📅 시공일 등록 → 추천 +1!"
3. 한도 도달 시 upsell 모달

### 박았을 때 사장님 폰 변화
- **베타 사장님 (지금 본인 포함) 체감 변화 ≈ 녹음 5분 cap 만**
- 한도 / 충전 = 정식 출시 시 작동 (베타 무제한이라 안 보임)
- 진짜 가치 = "정식 출시 인프라 준비"

## 6. 미래 cycle (큰 작업)

| 우선순위 | 작업 | 비고 |
|---|---|---|
| ⭐⭐⭐ | 자동 답장 (옵트인) | 패턴 분석 + 모달 + 자동 발송. 가장 큼. |
| ⭐⭐⭐ | 부재중 자동회신 | 안드로이드 CallReceiver + SMS 권한 |
| ⭐⭐ | 시공일 D-1 자동 알림 | 안드로이드 BG worker + 서버 endpoint |
| ⭐⭐ | 시공완료 → 결제 요청 자동 | 안드로이드 + 서버 |
| ⭐ | 결제 시스템 | 별도. 토스 또는 카카오페이 결합. |
| ⭐ | 캘린더 KPI funnel | [1] SMS 수신 (안드로이드) → [2] 접수서 제출 → [3] 시공일 등록 |

## 7. 미해결 질문 (사장님 결정 대기)

1. **베타 사장님 = 진짜 무제한? 아니면 체험용으로 일부 한도?**
   - 추천 A: 무제한 (베타 답례)
   - 옵션 B: 베타도 한도 (사장님 본인 체감 + 피드백)

2. **이번 cycle 박을지 미룰지?**
   - 옵션 A: 박음 (정식 출시 인프라 준비)
   - 옵션 B: 더 본질적 작업 (자동 답장 + 부재중 자동회신) 부터
   - 옵션 C: 다른 일 (캘린더 KPI 등)

3. **유료 가격 = 월 5만원? 다른 가격?**
   - 사장님 가설 = 5만원
   - cowork 의견 = 3-5만원 사이 (시공자는 5만원도 OK 한다 사장님 본인 판단)
