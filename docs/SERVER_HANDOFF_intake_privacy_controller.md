# SERVER 핸드오프 — 접수서(고객용) 3건: 개인정보 처리자 문구 + 결제 문구 + 설문 뒤로가기

작성: android Claude (2026-07-10). 담당: **server/cowork (맥미니)** — 전부 서버 렌더(main.py 의 고객 접수서 웹 + api.si0in.kr/privacy).
사장님(디테일라인) 실사용 중 발견. 앱(app/) 영역 아님 → android 는 못 고침.

---

## ★ 1순위 — 개인정보 "처리자 vs 수탁" 문구 (법적 정확성)

**문제**: 고객이 접수서에 적는 개인정보(연락처·현장 주소·메모)의 **실제 주인(개인정보처리자)은 시공하는 사장님(업체)** 인데,
지금 접수서 동의문구·처리방침은 **"막내컴퍼니(회사)가 수집한다"** 는 뉘앙스라 실제 데이터 흐름과 안 맞음.
사장님 지적(정확함): "이 DB 를 가져가는 건 이 앱을 운영하는 사장인데…".

**맞는 구조 (개인정보보호법)**:
- **사장님(업체) = 개인정보처리자(controller)** — 시공 접수·일정 목적으로 고객 정보를 수집·이용하는 주체.
- **막내컴퍼니 = 수탁자(처리위탁, processor)** — 앱·서버로 그 정보를 대신 보관·처리.

**요청 작업**:
1. **접수서 (필수) 동의 문구** 를 처리자=사장님/업체, 막내컴퍼니=수탁 으로 명확히. 접수서는 owner(사장님)별로 발급되므로 **업체명/사장님 상호를 동적으로** 넣을 수 있음.
   - 현재(고객 화면): `(필수) 개인정보 수집·이용 동의 — 연락처·현장 주소·메모를 시공 접수와 일정 확정 목적으로 수집하며, 시공 완료 후 최대 1년 보관 후 파기합니다. 동의하지 않으면 접수가 불가능합니다.`
   - **draft(법률 검토 전제)**: `(필수) 개인정보 수집·이용 동의 — [업체명/○○ 사장님]이 시공 접수·일정 확정을 위해 연락처·현장 주소·메모를 수집·이용합니다. 앱 운영사 막내컴퍼니가 이를 위탁받아 안전하게 보관·처리하며(처리위탁), 시공 완료 후 최대 1년 뒤 파기합니다. 동의하지 않으면 접수가 불가능합니다.`
2. **api.si0in.kr/privacy 처리방침** 에도 controller(사장님)/processor(막내컴퍼니) 역할 분리를 반영(현재 v3 = 막내컴퍼니 중심 서술). §처리위탁/제3자 항목 정합성 확인.
3. **⚠️ 이건 법률 판단** — android 가 문구 확정 못 함. cowork 는 위 draft 를 시작점으로 넣되, **반드시 "법률/개인정보 전문가 확인 필요"로 사장님께 보고**. 플레이스토어 심사 중이라 데이터 안전 양식과도 엮임(PLAY_DATA_SAFETY / 데이터 안전 감사 문서와 정합성 확인).

## 2순위 — 접수서 결제 문구 (계약금 이미 받은 상태)

**문제**: 접수서는 **계약금을 이미 받은 뒤** 작성하는 흐름(사장님 명시). 그런데 문구가 "입금 계좌는 확정 후 안내" 라 모순
(고객은 이미 계약금 냈는데 "계좌 나중에 안내"라니 안 맞음).
- 현재: `계약금 100,000원 · 입금 계좌는 확정 후 안내드려요` (100,000 = 계약금 동적값)
- **요청(사장님)**: "시공 종료 후 잔금을 입금해주시면 됩니다" 식으로. 즉 **계약금=받음 / 잔금=시공 완료 후 입금** 을 표현.
- **draft**: `계약금 100,000원 · 시공 종료 후 잔금 [총액−계약금]원을 입금해주시면 됩니다` (잔금액 동적 계산; 총액·계약금 이미 서버가 앎)
- 참고: 사장님 기본 흐름은 "계약금 선입금 → 접수서". 계약금 미입금 케이스가 있으면 그때만 기존 "확정 후 안내"로 분기할지 cowork 판단(없으면 위 문구 고정).

## 3순위 — 접수서 설문 단계 "뒤로가기" 없음 (오조작 복구 불가)

**문제**: 접수서의 "마케팅에 도움돼요(선택)" 설문/동의 단계에서 **뒤로가기·수정 수단이 없어서**, 실수로 옵션을 탭하면
되돌려 고칠 수 없음(사장님: "실수로 눌렀는데 뒤로가기가 없네").
- **요청**: 설문/동의 단계에 **이전 단계로 / 선택 취소·재선택** 가능하게 (뒤로가기 버튼 또는 선택 해제 UI). 제출("접수 완료하기") 전엔 언제든 고칠 수 있게.

## 공통
- 전부 **고객이 보는 접수서 웹 + 처리방침** = server/main.py (+ 템플릿). app/ 무관.
- 찾기 힌트(현재 문자열): `입금 계좌는 확정 후 안내`, `마케팅에 도움돼요`, `시공을 접수합니다`, `막내컴퍼니(이하 "회사")`.
- 배포 후 사장님 폰에서 접수서 링크 재확인. 1순위(개인정보)는 **법률 확인 → 확정** 순서 권장.
