# Play 「SMS 및 통화 기록 권한」 선언 — 제출 자료 (2026-07-05)

## 1. 핵심 기능(use case) 선택
**"기본 SMS 핸들러"** 만 체크. (기존 "엔터프라이즈 보관처리, CRM, 기기 관리" 는 **체크 해제** — 그게 반려 원인)
- (원하면 "발신번호 표시, 스팸 감지 및 차단" 도 함께 — READ_CALL_LOG 로 전화 오는 고객 정보 카드 띄우는 기능. 없어도 됨.)

## 2. 검토 안내 (그 칸에 붙여넣기, 500자 이내)
```
시공막내는 1인 시공업자(줄눈 등)용 고객관리(CRM) 앱입니다. SMS/통화기록 권한은 "기본 SMS 핸들러" 기능에 사용됩니다: 사용자가 앱을 기본 문자앱으로 지정하면 고객과 SMS/MMS(사진) 송수신, 부재중 자동응답 문자, 고객별 문자 대화·통화 기록 조회를 합니다.

[기본 문자앱 지정 방법] 앱 실행 → 하단 "더보기" 탭 → 상단 "시작 체크" 카드 → "기본 문자 앱 지정" 옆 [설정] → 시스템 다이얼로그에서 시공막내를 기본 문자앱으로 확인.

READ_CALL_LOG = 전화 오는 고객의 정보·최근 통화 내역 표시용. 모든 데이터는 기기 내 처리 또는 개발자 자체 서버(AI 답변 추천용, 데이터 보안 섹션에 선언)로만 전송하며 제3자에게 판매·공유하지 않습니다.
```

## 3. 동영상 안내 (URL 칸)
YouTube **일부공개(unlisted)** 로 올리고 그 링크를 붙여넣기.

### 시연 영상 대본 (폰 화면 녹화, 40~60초)
> 폰에서 "화면 녹화" 켜고 아래 순서대로. 말/자막 없어도 됨 — **동작만 보이면 됨.**

1. **(5초)** 시공막내 앱 열기 → 홈(상담함) 잠깐 보여주기 (CRM 앱임을 보여줌)
2. **(10초)** 하단 **더보기** 탭 → 맨 위 **"시작 체크"** 카드에서 **"기본 문자 앱 지정"** 의 **[설정]** 누르기
3. **(10초)** 시스템 다이얼로그 **"시공막내를 기본 문자앱으로?"** 뜨면 → **확인/기본값으로 설정** 누르기 → 체크(✓) 되는 것 보여주기
4. **(15초)** 핵심: **다른 폰에서 사진문자(MMS)를 보내고** → 시공막내에 **알림 오고 → 문자방 열면 사진 뜨는 것** 보여주기 (= 기본 SMS 핸들러로 동작 증명)
5. **(끝)** (선택) 전화 오면 뜨는 고객 정보 카드 or 자동응답 문자 화면 잠깐

→ 이게 "기본 SMS 핸들러 기능이 실제로 동작한다"는 증명이라 심사 통과에 가장 중요.
