# 박람회 계약서 — 템플릿 방식 재설계 (2026-07-24 사장님)

## 왜 (사장님)
지금 우리 계약서 = "상품 자유등록 → 상담사가 고르기". 유연하지만 **정리된 양식 느낌이 약함**.
사장님이 실제 쓰는 계약서(하늘숲 홈케어)는 **정해진 양식에 체크만** 하는 구조 → "한 장에 딱" 정리됨.
→ **줄눈 표준 템플릿을 첫 틀로.** 다른 업종 업체가 요청하면 **그 업체용 템플릿을 우리가 제작**(추가)해준다.

## ✅ 확정 (2026-07-24 사장님 "고고")
- 레이아웃 = **조밀형**(한 화면에 딱). 시안: `scratchpad/expo_contract_v3.png` · 아티팩트 https://claude.ai/code/artifact/cc1dd950-1243-420b-b019-75bd436e3ffe
- 항목/재질/청소 = 아래 그대로 확정.
- **워크플로우 핵심**: 상담사는 **항목 체크 + 가격만 입력**하면 계약 완성. 나머지(단지·약관·업체=방세팅 / 고객정보·입주일·서명=고객 / 시공항목=체크)는 자동.

## 아키텍처
**템플릿 = 서버에 두는 데이터.** 새 업체 틀 = 서버에만 추가 → 앱 업데이트 없이 적용. 앱은 방의 template_id 로 정의를 받아 그대로 렌더.
- `expo_rooms.template_id` (기본 `"julnun"`). 방 개설 시 지정(당분간 전부 줄눈).
- `expo_templates` (또는 서버 상수 JSON): 템플릿 정의(섹션·항목·재질·가격그룹·헤더필드).
- 계약(session/contract)은 **선택 결과**를 저장: 어떤 항목 체크·재질·가격.

## 줄눈 템플릿 정의 (`template_id="julnun"`) — 참고서 그대로

### 헤더 필드
- 단지명(방 기본정보 apartment) · 타입/평수(고객 선택 unit_type) · 고객명 · 연락처 · 주소(동/호) · 계약일 · 상담자(agent) · 입주일(신규 입력)

### 섹션 1 — 줄눈 시공 (matrix: 항목 × 재질)
- **재질(열)**: 폴리우레아 · 케라폭시  (항목마다 둘 중 체크)
- **항목(행)**: 현관바닥 · 욕실바닥(공용) · 욕실바닥(부부) · 샤워부스 3면벽 · 욕조 3면벽 · 욕실전체벽(공용) · 욕실전체벽(부부) · 세탁실 · 베란다 · 주방벽 · 아트월 · 거실폴리싱 · 포세린

### 섹션 2 — 실리콘 오염 방지 (checklist)
- 욕조테두리 · 변기테두리 · 욕실선반 · 욕조모서리 세로2줄 · 세면대

### 섹션 3 — 입주 청소 (checklist)
- 바닥기계 · 피톤치드 · 하자체크 · 나노코팅 · 친환경파인솔 · UV살균케어 · 새집증후군 · 마루거실코팅 · 에어컨 · 붙박이장 · 탄성 · 상판코팅

### 가격 그룹 (조밀 표 — 시안 v3, 상담사가 입력하는 유일한 타이핑)
- **줄눈**: 시공금액 · 예약금 · 잔금
- **청소**: 청소금액 · 예약금 · 잔금
- **총금액** · 입금자명

### 하단
- 특이사항(자유) · 계약 약관(방 기본정보 terms) · 업체정보(방 기본정보 biz_*)

## 서버 데이터 모델 (cowork 요청)
1. **템플릿 정의 제공**: `GET /api/expo/template/{id}` → 위 구조를 JSON 으로. (섹션 타입 matrix|checklist, 항목/재질, 가격그룹, 헤더필드) 당장은 `julnun` 하나. 서버 상수로 시작 가능.
2. **room 에 template_id**: `room/create`·`room/{id}` 에 `template_id`(기본 julnun).
3. **계약 선택 저장**: 실시간 세션/계약에 선택 결과 저장 필드.
   - 줄눈: `[{item, material}]` (체크된 항목+재질)
   - 실리콘/청소: `[item...]` (체크된 항목)
   - 가격: `{julnun:{total,deposit,balance}, cleaning:{total,deposit,balance}, grand_total, payer}`
   - `live/agent` 확장(또는 신규 필드)로 상담사가 체크→저장. `live GET`·`finalize`·`submissions`·영수증에 반영.
4. **영수증(`/expo/r`)**: 위 시안(구조화 양식)대로 렌더.

## 앱 플랜 (서버 나오면 단계별)
- P1: 방의 template_id → `template/{id}` 로 정의 로드.
- P2: 상담사 계약서 화면(현 QrView) = **자유상품 대신 템플릿 체크리스트**(줄눈 matrix + 실리콘/청소 checklist + 가격그룹). live/agent 로 선택 push.
- P3: 네이티브 계약서(ContractView) = 구조화 양식 렌더(시안 `scratchpad/expo_contract_v2.png`).
- P4: 접수서·달력은 그대로(요약은 선택항목 수/금액).
- (상품·서비스 등록 화면 = 줄눈 템플릿엔 불필요 → 템플릿에 자유상품 없으면 숨김.)

## 하위호환

- 시안: `scratchpad/expo_contract_v2.png` (구조화 계약서).
