01 / 출발 전

“오늘 두 군데인데,
어디부터 가더라?”

내 시공도, 다른 사장님과 함께하는 현장도.
날짜를 누르면 그날 일이 시간순으로 보입니다.

  1. 아래의 ‘일정’을 누르세요.달력에서 오늘 날짜를 고릅니다.
  2. 첫 현장의 시간과 주소를 확인하세요.내 현장과 수락한 협업 현장을 같이 볼 수 있어요.
  3. ‘길찾기’로 출발하세요.처음에는 사용할 내비 앱을 고르면 됩니다.
막내 팁 다른 사람에게 달력을 보여줄 땐 ‘금액’을 꺼두세요.
아침엔 이 화면 하나부터
일정 → 날짜 선택 → 현장 확인
02 / 작업 중

“문자는 봤는데,
답장을 했던가?”

상담함에서 ‘답장 안 함’을 누르세요.
아직 응대하지 않은 문의부터 차례로 챙길 수 있습니다.

  1. 상담함 → ‘답장 안 함’을 누르세요.광고가 아닌 상담 중, 아직 답하지 않은 사람을 봅니다.
  2. 고객을 눌러 대화를 여세요.추천 답장이 있으면 내용과 금액을 확인하고 고쳐 보내세요.
  3. 전화로 끝냈다면 ‘확인’을 누르세요.답장 안 함 목록에서만 빠져요. 고객과 대화는 남습니다.
전화도 놓쳤다면 더보기 → 자동으로 챙기기에서 부재중 문자를 켜두세요. 정해둔 안내로 첫 응대를 이어갑니다.
읽은 문자도, 답하지 않았다면
상담함 → 답장 안 함 → 고객 대화
03 / 통화 직후

“무광이었나?
토요일이었나?”

작업하면서 받은 전화, 기억으로 견적 내지 마세요.
연결해둔 녹음으로 통화 내용을 시간 구간별로 확인합니다.

  1. 먼저 통화 녹음을 연결하세요.시작 설정에서 ‘자동으로 찾기’. 녹음이 없다면 전화 앱의 자동 녹음을 켜세요.
  2. 고객 대화에서 통화 요약을 여세요.자재, 작업 범위, 약속한 날짜를 다시 읽어보세요.
  3. 애매한 내용은 시각을 눌러 들으세요.AI 요약은 틀릴 수 있어요. 중요한 금액과 일정은 원래 통화로 확인하세요.
기억 대신 기록 시공막내가 직접 통화를 녹음하는 것은 아니에요. 휴대폰에 저장된 통화 녹음이 필요합니다.
“아, 이 얘기였지.”
고객 대화 → 통화 요약 → 시각을 눌러 재생

“견적서요?
지금 보내드릴게요.”

노트북을 켤 때까지 미루지 마세요.
대화에서 견적을 만들고, 내 상호와 도장이 담긴 문서를 문자에 붙입니다.

  1. 더보기에서 사업자 정보·가격표를 적으세요.상호, 대표, 직인과 자주 쓰는 시공 항목을 준비합니다.
  2. 고객 대화에서 ‘/견적’을 고르세요.품목·금액·계약금 확인 → ‘견적서(직인)로 보내기’를 누릅니다.
  3. ‘문자에 첨부’ 후 보내세요.예약을 받을 땐 ‘/접수서’. 고객이 적은 날짜와 주소를 확인하세요.
한 번 더 확인 접수서 카드의 일정 등록 상태를 확인하세요. 이미 정한 날짜가 있으면 그대로 지킬 수 있어요.
내 상호와 도장까지, 한 장에
고객 대화 → /견적 → 견적서 → 문자에 첨부

  3. 사진에 설명이 필요하면 ‘표시’를 누르세요.크게 보기에서 펜으로 표시하고 완료. 원본은 두고 표시한 사진을 새로 추가합니다.
다음 방문에도 A/S가 생기면 해당 건의 ‘A/S 잡기’로 날짜를 정하고 이전 기록을 다시 확인하세요.

8가지 사용법

01놓친 문의와 부재중 전화 챙기기+

상담함 → 답장 안 함 → 고객 선택으로 대화를 여세요. 답장하면 해당 목록에서 빠집니다. 전화로 해결한 건은 고객 줄의 ‘확인’을 눌러 정리하세요.

더보기 → 자동으로 챙기기 → 부재중 응답에서 기능을 켜고 보낼 안내 문구를 확인하세요. 문자 발송 권한이 필요합니다. 발송 실패 표시가 뜨면 대화에서 직접 연락하세요.

문구 예시 · “안녕하세요, 바른시공입니다. 지금 작업 중이라 전화를 못 받았습니다. 시공 지역과 원하시는 작업을 문자로 남겨주시면 확인하고 연락드릴게요.”
02통화 내용을 다시 확인하기+

시작 설정의 통화 녹음 연결 → 자동으로 찾기로 저장된 녹음을 연결하세요. 이후 고객 대화의 통화 요약을 열고, 시간 구간을 눌러 해당 녹음을 다시 들을 수 있어요.

녹음이 없다면 먼저 전화 앱의 자동 녹음을 켜세요. 요약이 사실과 다르거나 날짜·금액이 애매하면 녹음과 고객 확인을 기준으로 처리하세요.

03견적서와 접수서 보내기+

더보기 → 견적서·사업자 정보에 상호·대표·직인을, 가격표에 항목을 적으세요. 고객 대화에서 /견적을 고른 뒤 품목, 금액, 계약금, 시공일을 확인하고 견적서(직인)로 보내기 → 문자에 첨부를 누릅니다.

접수를 받을 땐 대화에서 /접수서를 선택해 링크를 보내세요. 고객이 적은 내용을 받은 뒤 접수 카드에서 날짜와 일정 등록 상태를 확인하세요. ‘/’ 대신 입력줄의 ‘⊕’ 메뉴로도 기능을 열 수 있어요.

예시 견적 · 욕실 벽면 보수 900,000원 + 자재·운반 300,000원 − 할인 50,000원 = 1,150,000원. 계약금 300,000원 / 잔금 850,000원. 부가세 포함 예시입니다.
04오늘 일정 확인하고 현장으로 출발하기+

일정 → 날짜 선택. 내 시공과 수락한 협업 현장을 시간순으로 확인하세요. 현장 카드의 길찾기를 누르고, 처음이면 사용할 내비 앱을 고르세요.

직접 등록할 땐 일정 화면 오른쪽 위 ＋ 또는 날짜를 길게 누르세요. 달력의 금액을 켜면 시공 건 총액을 만원 단위로 볼 수 있어요.

05협업 사장님 부르고 일당 정리하기+

고객 대화 → 고객 카드 → 해당 건 → 협업 부르기. 내 전화번호는 더보기의 사업자 정보에 먼저 등록하세요. 현장 주소와 날짜를 확인하고 사장님을 고릅니다. 목록에 없으면 번호로 부르기를 사용하세요.

사람별 일당, 도착 시간, 전해둘 말을 적어 요청하세요. 상대가 수락해야 협업이 시작됩니다. 상대는 더보기 → 협업 현장에서 받은 요청을 확인할 수 있어요.

협업 사장님 상세의 정산서 → 달 선택에서 완료된 현장을 모아 저장·공유하세요. 정산서를 만들거나 지급을 기록하는 동작은 은행 송금이 아닙니다.

06현관 비번, 자재 메모, 현장 사진 남기기+

고객 대화 → 고객 카드 → 해당 시공 건 → 현장 메모에 그 현장에서 기억할 내용을 적으세요. 같은 고객이라도 시공 날짜와 건을 확인하고 기록하세요.

현장 사진을 추가한 뒤 크게 보기의 표시에서 펜으로 동그라미나 화살표를 그릴 수 있어요. 색·굵기를 고르고, 실수한 획은 되돌리기. 완료하면 원본을 유지한 채 표시한 사진이 새로 추가됩니다.

07시공 완료와 잔금 받음을 따로 표시하기+

작업을 마치면 해당 시공을 완료로 표시하세요. 아직 잔금을 받지 않았다면 완납으로 표시하지 마세요. 상담함 → 잔금 대기 또는 정산에서 남은 금액을 확인합니다.

고객에게 안내한 뒤 실제 입금을 확인하고 전액 받았어요? → 네, 완납으로 기록하세요. 계약금은 계약금 받았어요로 별도 표시합니다. 금액을 잘못 적었다면 먼저 해당 시공 건의 금액을 바로잡으세요.

08내일 할 일과 다음 방문까지 챙기기+

보내기 창의 작은 시계에서 시간을 고르면 문자를 예약할 수 있어요. 상담함 위 예약한 문자에서 확인하고, 대화의 대기 말풍선에서 예약취소할 수 있습니다. 사진 예약 발송은 기본 문자 앱 설정이 필요해요.

날짜를 미룬 고객은 해당 건의 더보기 → 일정 보류, 다시 방문할 일은 A/S 잡기로 구분하세요. 마친 현장과 사진은 아래 내 기록에서 돌아보세요.

맞는 사용법이 없어요. ‘문자’, ‘사진’, ‘일당’처럼 짧게 찾아보세요.

줄눈을 하지 않아도 쓸 수 있나요?+

네. 타일, 도배, 필름, 방수, 마루, 욕실 리모델링 등 업종을 선택할 수 있고 직접 입력도 가능합니다. 고객과 전화·문자로 약속하고 현장에 가는 사장님을 위한 앱입니다.

막내가 모든 문자를 알아서 보내나요?+

추천 답장은 사장님이 확인하고 보냅니다. 부재중 문자 등 자동 기능은 ‘더보기 → 자동으로 챙기기’에서 설정한 동작을 따릅니다. 예약 문자는 정한 시각에 발송되므로 예약 내용을 확인하세요.

아이폰에서도 쓸 수 있나요?+

이 사용설명서는 Android 앱 기준입니다. 통화 요약에는 휴대폰에 저장된 녹음이 필요하고, 전화 앱·기기 설정에 따라 녹음 연결 상태가 달라질 수 있습니다.

협업 사장님에게 고객 대화도 보이나요?+

고객 전화번호와 고객 대화는 보이지 않습니다. 협업에 필요한 현장 주소·날짜·시간·사진과 전해둔 말을 확인합니다. 보낼 내용을 살펴본 뒤 요청하고, 상대가 수락하면 협업이 시작됩니다.

입금은 자동으로 확인해주나요?+

입금 여부는 사장님이 실제 내역을 확인하고 기록하세요. 시공 완료, 계약금 받음, 잔금 완납은 각각 확인하는 항목입니다. 일당 정산서를 공유하는 것도 실제 송금과는 별개입니다.
