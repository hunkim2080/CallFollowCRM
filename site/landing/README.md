# 시공막내 홈페이지 · 로컬 정적 사이트

`index.html`을 Chrome 또는 Edge로 열면 됩니다. 빌드·설치·서버가 필요 없습니다.

```text
D:\dev\CallFollowCRM\site\landing\index.html
```

PowerShell에서 열기:

```powershell
Start-Process 'D:\dev\CallFollowCRM\site\landing\index.html'
```

로컬 HTTP로 확인하고 싶은 경우에만:

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory D:\dev\CallFollowCRM\site\landing
```

그다음 `http://127.0.0.1:8765`를 엽니다. 서버는 Ctrl+C로 종료합니다.

## 구성

1. 첫 화면: 사장님과 막내의 역할, 상담함 화면, 업종 안내.
2. 막내와 하루: 07:30 일정, 09:40 문의, 11:20 통화 요약, 12:30 견적. 시간 탭으로 전환.
3. 협업 사장: 요청 작성 / 요청 수신 화면, 요청·수락·완료·정산 순서.
4. 현장 기록: 건별 출입 메모, 사진, 펜 표시, A/S.
5. 퇴근 전: 고객 잔금과 협업 일당 정산서, 내 기록으로 이어지는 사용 흐름.
6. 처음 시작하기: 업종·상호·지역, 권한, 녹음, 문구·견적 준비.
7. 검색 가능한 8가지 사용설명서.
8. 가격·이름·제공 범위를 모두 미정으로 남긴 요금제 카드 3개.
9. FAQ 5개와 마지막 시작 안내.

## 동작

- 실제 Android 화면 구성을 참고한 휴대폰 화면 10개. 앱과 연결하지 않는 설명용 목업입니다.
- 첫 상담함의 ‘답장 안 함’, ‘확인’, ‘예시 처음으로’는 로컬에서 동작합니다. 문의 확인은 고객·대화를 지우지 않는다는 흐름을 보여줍니다.
- 시간 탭은 클릭 및 좌우 방향키 / Home / End로 이동합니다.
- 사용법 검색은 한글 키워드, 빈 검색, 결과 없음, 전체 보기 복원을 지원합니다.
- 사용설명서와 FAQ는 기본 HTML `details`로 펼칩니다.
- 외부 라이브러리·CDN·웹폰트·분석 스크립트·서버 요청·브라우저 저장소를 사용하지 않습니다.
- 유일한 외부 이동은 Google Play 링크입니다. 다운로드·문자·협업·송금 동작을 흉내 내어 실제 전송하지 않습니다.
- 반응형 구간: 1100 / 820 / 700 / 359px. 동작 줄이기 설정과 키보드 포커스 지원.
- JavaScript를 꺼도 시작 안내·8가지 사용법·요금·FAQ는 읽을 수 있습니다. 화면 목업과 시간 탭은 JavaScript가 필요합니다.

## 검증과 한계

- `node --check app.js`: 통과.
- HTML 내부 앵커·탭 연결·ID 중복·로컬 자산 경로·UTF-8·브랜드 금칙어 검사: 통과.
- 화면 템플릿 10개 실행, 탭 전환·키보드 이동·가이드 검색 로직의 DOM 대역 검사: 통과. 실제 브라우저 검증을 대신하지 않습니다.
- 예시 금액 계산 검증: 견적 90만 + 30만 − 5만 = 115만, 계약금 30만 / 잔금 85만. 협업 완료 건 28만 + 30만 = 58만.
- 브라우저 화면 검증은 미완료입니다. Browser access host가 unavailable이었고, 네이티브 Chrome 접근도 `Computer Use was not approved to use Google Chrome`으로 거절됐습니다. 데스크톱·모바일 스크린샷 검증을 했다고 주장하지 않습니다.
- Play 링크는 앱의 실제 패키지명 `com.detailline.callfollowcrm`과 앱 내부 스토어 링크 형식을 따릅니다. 외부 조회가 실패해 공개 설치 가능 여부는 확인하지 못했습니다. 사이트 버튼도 ‘Google Play에서 보기’로 표기했습니다.
- 외부 Claude 프로토 원문은 확보하지 않았습니다. `docs/PROTOTYPES.md`의 상태와 저장소의 현재 Compose 구현·앱 내 데모를 대조했습니다.

사이트 폴더만 추가했습니다. 기존 앱·서버·문서 변경, git commit/push, 사이트 등록·배포는 수행하지 않았습니다.
