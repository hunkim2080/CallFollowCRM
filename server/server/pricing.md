# RING-GO 견적 가격표

> 이 파일은 RING-GO 자체 서버가 답변 추천 LLM 호출 시 **시스템 프롬프트에 동적으로 삽입**한다.
> 사장님이 가격을 수정할 때는 **이 파일만** 고치면 끝. 서버 재시작 불필요 (파일 mtime 감시).

---

## 공통 기준

- 모든 견적: **34평 이하 + 300각 타일** 기준
- 타일 크기가 300각보다 작으면 견적 상승 → **사진 요청 필요**
- **구축 기준**: 첫 입주가 아닌 집은 구축으로 간주

## 추가 비용 발생 가능 케이스

다음 조건이 있으면 **현장 확인 후 추가 견적**이 나갈 수 있다. 답변에는 가능성 언급만:

- 실리콘 제거 필요
- 셀프 줄눈 시공 흔적 제거 필요
- 누수 흔적이 있는 경우

---

## 견적 합산 규칙 (중요)

- **"욕조벽 3면 + 화장실 전체 벽" 동시 요청** → 욕조벽 별도 추가 X. **화장실 전체 벽 견적으로만** 잡기.
- **화장실 전체 벽** 항목은 "추가 시 70만원" — 화장실 바닥 견적에 *더해질 때만* 의미가 있다. 단독 견적 X.

## 미확정 정보 처리 (AI 답변 후보 만들 때)

견적 답변할 때 다음 중 하나라도 대화에서 명시 안 됐으면, **3개 답변 후보 중 하나는 정확한 견적이 아닌 "물어보는 답변"** 으로 잡는다:

| 미확정 항목 | 물어볼 문구 예시 |
|-------------|------------------|
| 신축/구축 여부 | "혹시 신축이세요, 아니면 입주한 적 있는 집인가요?" |
| 타일 크기 | "타일 사진 한 장 보내주시면 정확히 견적 드릴게요" |
| 시공 부위 | "어느 부위 시공하실 건지 알려주세요 (바닥만/벽만/전체)" |

## 답변 형식 가이드

SMS/카톡으로 보낼 거라 **표는 안 보임**. 짧은 줄별 나열 + 합계 형식:

좋은 예:
```
신축 기준 견적입니다.
- 욕조있는 화장실 바닥 40만원
- 거실 타일 150만원
합계 190만원

실리콘 제거나 셀프줄눈 흔적 있으면 현장 확인 후 추가될 수 있어요.
```

나쁜 예 (피해야 할 것):
- 표 형식 (`|...|...|`)
- 너무 긴 설명
- "안녕하세요" 같은 인사말 임의 추가
- 이모지
