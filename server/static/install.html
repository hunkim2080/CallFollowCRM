자주 묻는 질문
요금이 나가나요?
고객 카드·견적서·접수서·일정·정산 같은 기본 기능은 기간 제한 없이 무료입니다. 통화 녹음과 통화 요약도 무료예요. 결제 수단 등록 자체가 없어서 동의 없이 나갈 돈이 없습니다. 자세한 건 요금제에서 보실 수 있어요.
기존에 쓰던 번호 그대로 쓸 수 있나요?
네. 사장님 전화번호를 그대로 씁니다. 번호를 새로 개통하거나 바꾸실 필요가 없어요.
막내가 마음대로 답장하나요?
아니요. 막내는 답장 초안만 만들어 두고, 발송은 항상 사장님이 ▶ 버튼을 누르셔야 나갑니다. 어색한 답장이 저절로 나갈 일은 없어요.
개인정보·문자 내용은 안전한가요?
문자·통화 원본은 서버에 영구 저장하지 않고, AI 처리에도 학습에 쓰이지 않는 유료 채널만 씁니다. 자세한 내용은 개인정보 처리방침에 있습니다.
아이폰도 되나요?
지금은 안드로이드 전용입니다. 전화·문자와 깊게 붙어야 하는 앱이라 안드로이드부터 완성도 있게 만들고 있어요.
