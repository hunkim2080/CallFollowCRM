오신 걸 환영해요

아래 3단계만 따라하시면 바로 시작하실 수 있어요.

1
설정에서 출처 허용하기
안드로이드 설정 → 앱 → 특별 액세스 → 알 수 없는 앱 설치 →
이 페이지를 연 브라우저 (Chrome / Samsung Internet) 를 찾아서 "이 출처 허용" 켜주세요.
💡
안드로이드 12 이상은 기본적으로 차단돼 있어요. 한 번만 켜두시면 다음에 또 안 물어봐요.
2
APK 다운로드
아래 버튼 누르면 시공막내 APK 파일이 다운로드돼요. 폰 용량 20MB 정도 차지해요.
⬇ 시공막내 APK 다운로드
버전 확인 중... 크기 확인 중...
⚠️ 아직 APK 가 업로드 안 됐어요. 사장님 안드로이드 빌드 후 곧 활성화돼요.
3
탭해서 설치하기
다운로드 완료 알림이 뜨면 탭 → "설치" 누르기. 끝!
홈 화면에 "시공막내" 앱이 생겨요. 처음 열면 사장님 정보 입력하시면 시작.
자주 묻는 질문
왜 Play 스토어 가 아니에요? +
베타 100명만 모집하는 단계라 Play 스토어 등록 전이에요. 정식 출시 시점에는 Play 스토어에서 자동으로 받으실 수 있게 안내드릴게요.
"바이러스 위험" 경고가 떠요. 괜찮나요? +
안드로이드는 Play 외 다운로드를 기본적으로 경고해요. 시공막내 APK 는 사업자 정보가 명시된 디테일라인이 직접 빌드한 정식 앱이에요. "그래도 설치" 또는 "신뢰" 누르시면 돼요. 정식 출시 후엔 이런 경고 없어요.
설치가 안 돼요. +
대부분 1단계 "출처 허용" 을 안 한 경우예요. 다시 설정 → 앱 → 특별 액세스 → 알 수 없는 앱 설치 에서 사용 중인 브라우저 허용했는지 확인해주세요. 그래도 안 되면 hello@si0in.kr 으로 문자주세요.
개인정보·문자 내용 안전한가요? +
SMS 원문은 서버에 저장 안 해요. 학습은 사장님이 직접 업로드하신 답장 예시만 사용. 베타 종료 시 모든 데이터 즉시 파기. 자세한 정책은 첫 실행 시 보여드려요.
iPhone 도 되나요? +
베타는 안드로이드 (Galaxy / 갤럭시 등) 만 지원해요. iOS 는 정식 출시 시점에 검토 중입니다.
