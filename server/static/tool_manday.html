공수란?

공수(工數)는 투입 인원 × 작업 일수로 계산하는 인력 단위예요. 3명이 2일 일하면 6공수입니다. 하도급 정산·인건비 견적의 기본 단위가 됩니다.

공수로 인건비 계산하기

총 인건비 = 공수 × 1인 1일 일당. 위 예시면 6공수 × 25만원 = 150만원입니다. 일당이 직종·지역마다 다르니 실제 단가를 넣어 확인하세요.
