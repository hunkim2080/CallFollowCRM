부가세 별도 vs 포함

별도는 적은 금액에 10%를 더 받는 것(100만원 → 110만원), 포함은 그 금액 안에 부가세가 들어있는 것(110만원 안에 공급가 100만 + 부가세 10만)입니다.

왜 명확히 해야 하나

견적을 "100만원"이라고만 하면 고객은 포함으로, 사장님은 별도로 생각해 잔금 때 다툼이 생깁니다. 견적서에 부가세 별도/포함을 반드시 명시하세요.
