개인정보 처리방침

시공막내 · 디테일라인이 제공하는 시공 사장님 운영 비서 앱

시행일: 2026년 6월 17일 · 최종 개정일: 2026년 7월 6일 (v2 — 가입 인증·문자 발송 위탁 추가)

디테일라인(이하 "회사")은 시공막내(이하 "서비스")를 운영하면서 「개인정보 보호법」 및 관련 법령을 준수하고, 정보주체의 개인정보를 안전하게 보호하기 위해 다음과 같이 개인정보 처리방침을 수립·공개합니다.

1.개인정보 처리 목적

회사는 다음의 목적을 위하여 개인정보를 처리합니다. 처리한 개인정보는 아래의 목적 외 용도로는 사용하지 않으며, 이용 목적이 변경되는 경우에는 사전에 동의를 받습니다.

  1. 서비스 제공 — 시공 사장님의 통화·문자·일정·견적·정산·협업 관리 기능 제공
  2. 회원 식별 및 베타 테스터 관리 — 휴대전화 번호 기반 본인 확인, 베타 화이트리스트 관리
  3. 고객 응대 보조 — 사장님의 통화 녹음·문자 메시지를 AI로 요약·정리, 답장 추천 생성
  4. 서비스 안정성 확보 — 부정 이용 방지, 서비스 품질 개선, 통계 분석
  5. 안내 발송 — 공지사항·업데이트 알림, 협업 요청 알림(FCM 푸시)

2.처리하는 개인정보 항목

회사는 서비스 제공을 위해 다음의 개인정보를 처리합니다.

2-1. 사장님(서비스 이용자) 정보

구분항목수집 시점
필수휴대전화 번호, 가입 인증번호 확인 기록회원 가입(SMS 인증) 및 앱 첫 진입
선택상호명, 업종, 지역온보딩 시 직접 입력
자동FCM 푸시 토큰, 앱 사용 시각·횟수앱 사용 중 자동 수집
자동휴대전화 기기 정보 (OS 버전, 기기 모델)API 호출 시

2-2. 고객 정보 (사장님이 응대하는 자기 고객)

사장님이 자신의 고객을 응대하기 위해 앱에 저장하는 정보는 원칙적으로 사장님의 휴대전화 안에서만 처리되며, AI 응대 보조 기능 사용 시 일부 항목이 서버로 전송됩니다.

항목저장 위치서버 전송 여부
고객 휴대전화 번호사장님 폰일부 기능 한정(예: AI 답장 추천 호출 시 익명화 식별자만)
고객과의 통화 녹음 파일사장님 폰요약 요청 시 텍스트만(원본 음성은 일시 처리 후 즉시 삭제)
고객과의 문자 메시지 본문사장님 폰답장 추천 요청 시(원본은 서버에 저장하지 않음)
고객 메모, 시공 일정, 견적 금액사장님 폰요청한 사장님 본인의 분석 기능에 한해 사용
현장 사진사장님 폰 + 서버(협업 공유 시)사장님이 명시적으로 협업 사장에게 공유한 경우에 한함

2-3. 통화·문자 자동 처리 (시공막내 핵심 기능)

통화 녹음 파일 및 문자 메시지는 다음 원칙으로 처리됩니다:

  • 사장님이 명시적으로 권한을 허용한 경우에만 접근
  • 원본 파일은 서버에 영구 저장하지 않음 (요약 텍스트만 저장)
  • 외부 AI 모델(Anthropic Claude, Google Gemini)로 처리 시 학습용 데이터로 사용되지 않는 유료 API 채널 사용
  • 사장님이 앱에서 삭제하면 서버 캐시도 함께 파기

3.개인정보의 보유 및 이용 기간

  1. 베타 테스트 기간 데이터: 베타 서비스 종료 시 즉시 파기 (또는 사장님 요청 시 즉시 파기)
  2. 회원 정보: 회원 탈퇴 또는 베타 종료 시까지 보관. 탈퇴 후 30일 내 완전 파기
  3. 통화 요약 텍스트: 사장님이 앱에서 명시적으로 삭제할 때까지 (또는 서비스 종료 시)
  4. 접속 기록·로그: 「통신비밀보호법」에 따라 최대 3개월 보관 후 파기
  5. 법령에 따른 보존: 관련 법령에서 보존 의무를 부여하는 경우 해당 기간 동안 보관

4.개인정보의 제3자 제공

회사는 정보주체의 동의 없이 개인정보를 제3자에게 제공하지 않습니다. 다만 다음의 경우는 예외로 합니다.

  1. 정보주체로부터 별도의 동의를 받은 경우
  2. 법령에 특별한 규정이 있거나 수사기관이 법령에 따른 절차를 거쳐 요청한 경우
  3. 협업 기능을 사용하기 위해 사장님이 명시적으로 다른 사장님에게 일부 정보(현장명, 일정, 사진 등)를 공유한 경우 — 단, 고객 휴대전화 번호와 통화 내용은 절대 협업 상대방에게 공유되지 않습니다

5.개인정보 처리의 위탁

회사는 원활한 서비스 제공을 위해 다음과 같이 개인정보 처리 업무를 위탁하고 있습니다.

수탁자위탁 업무위치
Anthropic, PBCAI 모델(Claude) 호출을 통한 통화 요약·답장 추천 생성미국
Google LLCAI 모델(Gemini) 호출, FCM 푸시 전송, Play 서비스미국
Cloudflare, Inc.도메인 DNS, CDN, Tunnel 서비스미국
SOLAPI 주식회사가입 인증번호 및 서비스 안내 문자(SMS) 발송대한민국

각 수탁자와는 개인정보 보호법 제26조에 따라 위탁 계약을 체결하고, 처리 위탁 사실을 본 처리방침을 통해 공개합니다. 외부 AI 모델 호출 시에는 학습용 데이터로 사용되지 않는 유료 API 채널(Paid Tier)을 사용합니다.

6.정보주체와 법정대리인의 권리·의무 및 행사 방법

정보주체는 다음의 권리를 행사할 수 있습니다.

  1. 개인정보 열람 요구
  2. 개인정보 정정·삭제 요구
  3. 개인정보 처리 정지 요구
  4. 개인정보 처리 동의 철회

위 권리 행사는 회사에 대해 서면, 전자우편 등을 통하여 하실 수 있으며, 회사는 이에 대해 지체 없이 조치하겠습니다. 또한 앱 내 설정 메뉴에서 직접 데이터 삭제·계정 탈퇴를 진행할 수 있습니다.

7.개인정보의 파기

회사는 원칙적으로 개인정보 보유 기간이 경과하거나 처리 목적이 달성된 경우 지체 없이 해당 개인정보를 파기합니다.

  • 파기 절차: 파기 대상 개인정보를 선정한 후 회사의 개인정보 보호책임자의 승인을 받아 파기
  • 파기 방법: 전자적 파일 형태는 복구·재생할 수 없는 방법(완전 삭제)으로 파기, 종이 문서는 분쇄 또는 소각

8.개인정보의 안전성 확보 조치

회사는 개인정보의 안전성 확보를 위해 다음의 조치를 취하고 있습니다.

  • 관리적 조치: 내부 관리 계획 수립·시행, 정기적 자체 감사
  • 기술적 조치: 개인정보 처리시스템 접근 권한 관리, 암호화 통신(HTTPS), 보안 프로그램 설치
  • 물리적 조치: 서버실·자료보관실 접근 통제

9.아동의 개인정보 보호

본 서비스는 만 18세 이상의 시공업 종사자를 대상으로 합니다. 회사는 만 14세 미만 아동의 개인정보를 수집하지 않습니다.
