막내가 하는 일은
딱 3가지입니다

기능은 많지만, 외울 필요 없습니다. 사장님이 기억할 건 이 세 줄이 전부예요.
(박람회·전시회 뛰는 팀이라면, 전용 모드도 준비돼 있어요.)

하나

전화를 놓쳐도,
고객은 놓치지 않게

현장에서 손을 못 떼는 건 사장님 잘못이 아닙니다. 그동안 막내가 응대합니다.
  • 전화 오면 "지난주 방수 문의하신 분" — 고객 카드가 먼저 뜹니다
  • 못 받으면 자동 문자가 나갑니다 — 고객이 다른 업체로 새지 않아요
  • 통화가 끝나면 AI가 요약 — 평수·부위·희망일이 글로 남습니다
  • 답장은 AI 추천 3개 중 골라서 10초 — 내 말투로 다듬어 줍니다
둘

문자 한 통이
계약서가 되게

"300이요" 한 줄 대신, 직인 찍힌 문서가 나갑니다. 딴말이 안 나옵니다.
  • 항목 몇 개 고르면 직인 견적서 이미지가 30초 만에
  • 부가세 별도/포함이 버튼 하나로 명시 — 분쟁의 절반이 사라집니다
  • 같이 나가는 접수서 링크에 고객이 주소·연락처를 직접 적습니다
  • 제출된 내용은 읽기 전용 영수증으로 — "말이 달랐다"가 성립 안 해요
셋

일정과 돈은
앱이 대신 지키게

사람의 기억력에 기대는 시스템은 성수기에 무너집니다. 구조가 지킵니다.
  • 접수서가 제출되면 일정에 자동 등록 — 손으로 적는 단계가 없습니다
  • 시공 하루 전, 고객에게 안내 문자 자동 발송 — 겹침·펑크 예방
  • 계약금·잔금이 현장별로 — 못 받은 돈이 화면에 남아 있습니다
  • 다른 사장님과 협업 현장 공유 — 도착·완료·정산까지 한 화면
＋ 박람회·전시회 모드

부스에서 팀으로 뛰는 날,
계약서까지 한 번에

박람회·전시회는 따로 운영해요. 팀장이 방을 열고, 팀원과 나눠서, 고객 앞에서 바로 계약합니다.
  • 팀장이 방 개설 → 팀원 초대 — 부스마다 우리 팀 것만 따로 봅니다
  • 상품 카탈로그 계약서를 미리 세팅 — 업종별 항목을 고객과 보며 체크
  • 고객 폰에 QR → 항목 확인·서명·개인정보 동의, 한 부씩 저장
  • 접수서를 팀원에게 배정 → 일정 등록률·시공 완료률 두 눈금으로 진행 파악
  • 우리 팀 접수서 모아보기 — 전화 뒷 4자리만 노출로 안전하게
