전화 받고, 견적 보내고, 일정 잡는 일
이제 막내한테 시키세요

현장에서 손에 시멘트 묻히고 있는 동안에도, 시공막내가 고객 응대를 준비해 둡니다.

📞 전화·문자 — 놓친 고객이 사라집니다
🪪

전화 오면 고객 카드

모르는 번호가 아니라 "지난주 욕실 방수 문의하신 분"으로 뜹니다. 받기 전에 누군지 알고 받으세요.

📝

AI 통화 요약AI

통화 끝나면 녹음이 요약으로 바뀝니다. "평수·부위·희망일·예산"이 정리돼서 다시 들을 필요가 없어요.

💬

추천 답장 + 말투 다듬기AI

고객 문자에 보낼 답 3개를 만들어 드립니다. 내 말투로 학습해서, 갈수록 사장님답게 씁니다.

🌙

부재중 자동 응대

현장이라 못 받은 전화에 "확인 후 연락드리겠습니다" 문자가 먼저 나갑니다. 고객이 다른 업체로 새지 않아요.

📄 견적·접수 — 종이 없이, 분쟁 없이
🧾

직인 견적서 이미지

항목 몇 개 고르면 직인 찍힌 견적서가 이미지로 나옵니다. 부가세 별도/포함까지 명시돼서 나중에 딴말이 안 나와요.

🔗

시공접수서 링크

고객에게 링크 하나 보내면 주소·연락처·희망사항을 고객이 직접 적어 냅니다. 제출되면 일정에 자동으로 들어가요.

✅

제출 완료 영수증

고객이 낸 접수서는 언제든 같은 링크에서 다시 확인. 시공일·금액·특이사항이 읽기 전용으로 남습니다.

📌

발행 이력

보낸 견적서·접수서가 고객별로 차곡차곡. "그때 얼마로 드렸더라?"가 3초면 나옵니다.

🗓️ 일정·정산·협업 — 사무실 없는 사무실
⏰

일정 + 하루 전 안내

시공 하루 전, 고객에게 안내 문자가 자동으로 나갑니다. "내일 가는 거 맞죠?" 전화를 안 받아도 됩니다.

💰

수금·정산 관리

계약금·잔금이 현장별로 정리됩니다. 못 받은 돈이 화면에 남아 있으니 잊고 넘어가는 일이 없어요.

🤝

협업 현장 공유

다른 사장님과 현장을 공유하고, 도착·완료·증거사진·일당 정산까지 한 화면에서. 전화 안 해도 진행이 보입니다.

📮

정기 문자 예약

AS 안내, 명절 인사, 시즌 점검 문자를 미리 걸어두세요. 단골은 이렇게 만들어집니다.

🔍 이렇게 흘러갑니다
  1. 전화가 옵니다 — 고객 카드가 뜨고, 못 받으면 자동 문자가 나갑니다.
  2. 통화가 끝납니다 — AI가 요약하고, 답장 추천을 준비합니다.
  3. 견적을 보냅니다 — 직인 견적서 이미지 + 시공접수서 링크를 문자 한 통으로.
  4. 고객이 접수서를 냅니다 — 일정에 자동 등록, 하루 전 안내 문자까지 예약됩니다.
  5. 시공이 끝납니다 — 잔금이 정산 목록에, 고객은 단골 목록에 남습니다.
