자동 발송인가요? 막내가 마음대로 답장하나요? +
절대 아니에요. 막내는 답장 초안만 만들어드리고, 발송은 항상 사장님이 ▶ 버튼 한 번 누르셔야 나가요. 실수로 어색한 답장이 나갈 일 0.
제 톤이랑 다르게 답장하면 어쩌죠? +
평소 보내신 문자 (혹은 보내실 예시 몇 개) 를 막내가 학습해요. 처음엔 어색해도 며칠 쓰면 사장님 톤 그대로 답장합니다. 사장님이 손보신 내용도 학습돼요.
문자만? 카톡·전화는요? +
현재 베타는 SMS·MMS 만 지원. 통화 정리 (받은 통화 요약·후속 문자 작성) 도 지원해요. 카톡은 정식 출시 시점에 검토 중.
개인정보·문자 내용 안전한가요? +
SMS 원문은 서버에 저장 안 함. 학습은 사장님이 직접 업로드하신 답장 예시만 사용. 베타 종료 시 모든 데이터 즉시 파기.
베타 끝나면 얼마예요? +
정식 출시 가격은 베타 결과 보고 확정. 베타 참여자는 평생 50% 할인 보장합니다.
