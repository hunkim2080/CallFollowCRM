업데이트 소식

사장님들이 "이거 되면 좋겠다" 하신 것들이 이렇게 됩니다. 매주 좋아지는 막내입니다.

2026. 7. 둘째 주

견적서에 부가세 별도/포함 명시 — 분쟁 예방 업데이트

  • 견적서·시공접수서에 부가세 별도/포함이 명확히 표시됩니다. 발행할 때 버튼 하나로 선택하세요.
  • 고객이 제출을 마친 접수서 링크를 다시 열면 확인용 영수증이 보입니다 — 시공일·금액·특이사항을 언제든 다시 확인.
  • 협업 현장에 올린 증거사진을 개별 삭제할 수 있습니다 (내가 올린 사진만).
  • 삼성 기기에서 사진 문자(MMS) 발송이 차단되던 문제를 해결했습니다.
  • 추천 답장 화면 깜빡임과 "다듬기" 버튼이 작아 누르기 어렵던 부분을 개선했습니다.
2026. 7. 첫째 주

발행 이력 — "그때 얼마로 드렸더라?"가 3초

  • 보낸 견적서·접수서가 고객별로 저장됩니다. 고객 상세의 "발행 이력"에서 언제든 다시 열람·재공유.
  • 접수서에 사장님 특이사항 메모를 담을 수 있습니다 (예: "2층 화장실만", "주차는 후문").
  • 접수서를 재발행해도 링크는 그대로 — 고객이 헷갈릴 일이 없습니다. 내용만 갱신돼요.
  • 시공일이 하루 밀려 표시되던 문제를 해결했습니다.
  • 개인정보 보호 강화 — 동의 절차 정비, AI 안내 문구 추가. 사장님과 고객 모두를 지키는 업데이트입니다.
2026. 6.

협업 — 다른 사장님과 현장을 함께

  • 협업 현장 공유: 일감을 나눌 사장님에게 현장 정보를 링크로 공유하고, 도착·완료·정산까지 한 화면에서.
  • 협업 상대가 현장 3km 안에 들어오면 자동 도착 표시 — 전화로 "어디쯤이세요?" 안 해도 됩니다.
  • 완료 시 증거사진·계좌 전달로 일당 정산까지 매끄럽게.
2026. 5. ~

시공막내의 기본기

  • 전화 오면 고객 정보 카드, 통화 끝나면 AI 요약, 답장은 AI 추천 3개.
  • 직인 견적서 이미지 + 시공접수서 링크 — 문자 한 통으로 견적부터 접수까지.
  • 접수서 제출 시 일정 자동 등록, 시공 하루 전 자동 안내 문자.
  • 계약금·잔금 정산 관리, 정기 문자 예약.
