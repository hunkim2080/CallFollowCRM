🔔 RING-GO 가 띄우는 알림 모음

각 알림이 언제 뜨고, 왜(어떤 기준으로) 뜨는지 한 곳에 정리했어요.

색의 뜻
🔵 파랑 = 정보·브리핑   🟢 초록 = 출발·도착·입금   🟣 보라 = 접수·협업
🟠 주황 = 확인 필요(보낼까요?)   🔴 분홍 = 못 받은 돈   🟦 청록 = 정기문자
“즉시” = 일이 생기는 그 순간 / “예약” = 정해진 시간대에 앱이 스스로 점검해서
📐 알림은 두 가지 모양으로 떠요

화면 위 카드  = 화면 한가운데에 큼직하게 뜨는 카드(오버레이). 요약·초안·버튼이 한 장에 다 있어요. ‘다른 앱 위에 표시’ 권한이 켜져 있어야 떠요.
→ 통화 후 카드 가 대표예요. (사장님이 말한 “이 알람”)

상단 푸시  = 핸드폰 맨 위에서 아래로 내려오는 보통 알림(헤드업). 누르면 해당 화면으로.
→ 새 문자·접수서·브리핑·잔금·D-1·팀/협업 알림이 다 이거예요.

※ 화면 위 카드 권한이 꺼져 있으면, 카드 대신 상단 푸시로 대체돼서 떠요.

💡 막내의 솔직 검토 & 개선안

원칙 하나: 알림은 적고 정확할수록 신뢰가 커져요. 너무 자주 울리면 사장님이 알림을 꺼버리고, 그러면 정작 중요한 걸 놓쳐요. 그래서 “꼭 필요한가 / 지금 울리는 게 맞나”를 기준으로 봤어요.

🟡유용하지만 조건 손질: 부재중 자동문자 · 마감 브리핑 · D-1 · 팀원/협업 진행 · 현장 도착 5km
🔴줄이거나 합치기: “RING-GO 캐치!”(내가 건 전화에도 뜸) · 팀원 ‘출발’ 매번 · 같은 아침/저녁에 여러 개 따로 뜨는 것
항목별 — 왜 / 피로감 / 안 울려야 할 때 / 문구
1. 통화 후 카드 유지 · 핵심 기능. ⚠️ 단 내가 건 발신 통화 중에 ‘고객도 아니고 문자 이력도 없는 번호’(자재상·가족·택배)엔 뜨지 않게 — 안 그러면 전화할 때마다 카드가 떠서 피로해요. 받은 전화·기존 고객에만.
2. 부재중 자동문자 조건 손질 · 필요. ⚠️ 연락처에 저장된 비(非)고객(가족 등)·광고번호엔 자동발송 X. (스팸 앞자리는 이미 차단 중) “자동으로 문자 나가는” 기능이라 더 보수적으로.
3. “RING-GO 캐치!” 문구·조건 둘 다 · 이름이 뭘 하라는지 안 보여요. 또 내가 건 발신 통화에도 떠서 피로. 문구 → 방금 통화 · 후속 문자 보낼까요? 로, 그리고 발신 통화엔 끄기(고객일 때만).
4. 조용한 재통화 알림 유지 · 소리 없이 알림함에만 — 잘 설계됨. 그대로.
5. 새 문자 조건 손질 · 핵심. ⚠️ 인증번호(OTP)·광고 발신번호(1500·웹발신 등)는 알림 X → ‘진짜 고객 문자’만 울리게. (지금은 그런 것도 “새 문자”로 떠서 노이즈)
6. 접수서 회신 도착 유지 · 드물고 반가운 알림. 완벽. 그대로.
7. 마감 브리핑(밤 9시) 설정 추가 · 유용. 시간 바꾸기 / 끄기를 설정에 두면 좋아요. (아무 일 없는 날은 이미 안 옴 — 잘함)
8. 정기문자(오전 9시) 유지 · 보낼 게 있는 날만. 그대로.
9. 잔금 미수(오전 10시) 묶기 · 필요. ⚠️ 여러 명이면 하나로 묶어서 → 못 받은 잔금 3곳 · 합계 90만원 (지금은 고객마다 따로 → 아침에 여러 번 울림)
10. 시공 전날 D-1(저녁) 묶기 · 유용. 여러 건이면 묶어서. 토글은 그대로.
11. 팀원 출발/도착/완료 출발 선택 · 도착·완료는 중요. ‘출발’ 알림은 끌 수 있게(선택). 팀원이 여럿이면 하루 알림이 너무 많아져요.
12. 협업 진행(수락/출발/도착/완료) 출발 선택 · 수락·완료는 중요. 출발은 선택으로.
13. 협업 요청 유지 · 바로 행동(수락/거절)이 필요. 그대로.
14. 현장 도착 5km 안내 조건 중요 · ⚠️ ‘오늘 시공 예약된 고객’ 현장에만. 과거 고객 동네를 지나갈 때 울리면 안 돼요(가장 피로한 케이스).
15. 입금완료 / 협업 해제 유지 · 의미 있는 사건. 그대로.
전체 개선 원칙 (요약)
①종류별 ON/OFF — 설정에서 “팀원 출발”, “마감 브리핑” 등을 따로 끌 수 있게.
②묶음 — 같은 아침/저녁에 여러 건은 한 알림으로(잔금·D-1·팀원).
③발신 통화 최소화 — 내가 건 전화엔 카드/푸시를 최대한 안 띄움(고객·이력 있을 때만).
④노이즈 차단 — 인증번호·광고 문자, 비고객 번호엔 안 울림.
⑤방해금지 시간 — 밤 늦게(예: 22시 이후)는 소리 없이(꼭 필요한 것 제외).
⑥문구 톤 통일 — “~보낼까요?”처럼 다음 행동을 묻는 형태로.
※ 이건 막내의 제안이에요. 사장님이 “이건 그대로 / 이건 바꿔” 정해주시면 그대로 반영할게요.
