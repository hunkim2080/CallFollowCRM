2. 알림별 상세 명세

1. 새 문자 긴급
현재 문구제목 “{이름/번호} · 새 문자” / 본문 = 받은 문자 그대로 언제고객 SMS 수신 즉시(헤드업) 왜고객 응대 누락 방지(앱 핵심) 표시/버튼상단푸시 · [💬 직접 답장](RemoteInput) 자동실행없음 중복방지번호별 동일 ID 갱신 개인정보높음 — 문자 본문이 잠금화면에 노출 문제점① 인증번호(OTP)·광고도 “새 문자”로 울림 ② 잠금화면 본문 노출 수정① 인증/광고 발신번호(15xx·웹발신) 제외 ② setVisibility(PRIVATE)로 잠금화면엔 “새 문자”만 추천 문구유지(“{이름} · 새 문자”)
수정(조건·개인정보)
2. 통화 후 카드 중요
현재 문구“방금 통화 종료 · {번호}” + ✨통화 정리 중… 언제통화(수신·발신) 5초 이상 후 종료 왜상담 요약 + 후속문자 초안 제공 표시/버튼팝업카드(권한X면 상단푸시 대체) · [다듬기][문자 보내기][닫기] 자동실행없음(사장 확인 후 발송) 중복방지이미 떠있으면 무시(showOrIgnore) 개인정보중간 — 번호·요약 화면 표시 문제점내가 건 발신 통화(자재상·가족 등 비고객)에도 매번 뜸 → 피로 수정발신은 ‘고객이거나 문자 이력 있는 번호’일 때만 추천 문구유지
수정(발신 조건)
3. 부재중 자동문자 중요 · ⚠️ 자동발송
현재 문구“부재중 자동 응답” + 설정 문구(신규/단골) 언제부재중/첫통화 + 자동문자 토글 ON → 10초 후 자동발송 왜못 받은 전화 즉시 응대 표시/버튼팝업카드/푸시 카운트다운 · [지금 보내기][취소] 자동실행예 — 10초 뒤 SMS 자동 발송 중복방지같은 번호 24h 1회(쿨다운) 개인정보낮음(내가 보내는 문자) 문제점저장된 비(非)고객(가족·지인)·광고 번호에도 자동 발송될 수 있음(오발송) 수정고객/문자이력 있는 번호에만. 연락처 저장된 비고객·광고는 제외. (스팸앞자리는 이미 차단) 추천 문구유지
수정(오발송 차단 — 오픈 전 필수)
4. 접수서 회신 도착 중요
현재 문구“시공접수서 회신 도착 🎉” + “{이름}…시공 희망 {날짜}·{금액}만원” + 📍주소 언제고객이 접수서 제출(앱 60초 폴링 감지) 왜주소·시공일·견적·계약금 자동 반영 알림 표시/버튼상단푸시 · [일정 확인] 자동실행없음(데이터 반영은 자동, 발송 아님) 중복방지token별 1회 개인정보높음 — 주소+금액이 잠금화면 노출 문제점주소·금액이 잠금화면에 그대로 보임 수정setVisibility(PRIVATE) — 잠금화면엔 “접수서 도착”만, 상세는 열어야 보이게 추천 문구유지
수정(개인정보)
5. 협업 요청 긴급
현재 문구“🤝 협업 요청이 왔어요” + “{사장님}이 ‘{현장}’ 협업을 요청…수락하기” 언제상대 사장이 현장 공유요청(FCM 즉시) 왜수락/거절 즉시 결정 필요 표시/버튼상단푸시 · [수락하러 가기] 자동실행없음 중복방지shareId별 · onlyAlertOnce(FCM+폴링 중복 방지) 개인정보낮음 — 보낸사람+현장명만(고객정보 벽) 문제점없음(잘 설계됨) 수정유지
유지
6. 잔금 미수 참고
현재 문구“아직 안 들어온 잔금이 있어요” + “{이름}·잔금 {N}만원·완료 후 {n}일째 미입금” 언제완료 3일 지났는데 미입금 · 오전 10시경 표시/버튼상단푸시 · [잔금 요청 보내기] 중복방지고객별 1회 개인정보중간(이름+금액) 문제점여러 명이면 같은 아침에 따로 여러 번 수정하나로 묶기: “못 받은 잔금 3곳 · 합계 90만원” 추천 문구묶음형으로 변경
수정(묶기)
7. 시공 전날 D-1 중요
현재 문구“내일 시공 — 안내 문자 보낼까요?” + “{이름}·{날짜}{시각}·{주소}” 언제전날 저녁(설정 시각) · D-1 토글 ON 표시/버튼상단푸시 · [안내 보내기] (확인 후 발송) 중복방지고객·날짜별 1회 개인정보중간(이름+주소) 문제점여러 건이면 따로 여러 번 · 주소 잠금화면 노출 수정여러 건 묶기 + 잠금화면 주소 가림 추천 문구유지(묶음 시 “내일 시공 N곳 — 안내 보낼까요?”)
수정(묶기·개인정보)
8. 협업 완료(정산) 중요 · ⚠️ 계좌 노출
현재 문구“협업 작업 완료 ✅” + “…작업을 끝냈어요 · 계좌 {은행 계좌번호 예금주}” 언제상대 사장이 ‘완료’ 누름 표시/버튼상단푸시 · [협업 현장 보기] 개인정보높음 — 입금 계좌번호가 알림/잠금화면 노출 문제점계좌번호가 잠금화면에 그대로 — 노출/촬영 위험 수정알림엔 “완료 · 정산하기”만, 계좌는 앱 안에서. setVisibility(PRIVATE) 추천 문구“협업 완료 — 정산 계좌 확인” (계좌번호는 본문에서 빼기)
수정(개인정보 — 오픈 전 필수)
9. 협업 진행(수락/출발/도착) 참고
언제상대 사장 진행 버튼(수락/출발/도착) 표시상단푸시(헤드업) 문제점출발·도착까지 다 헤드업 → 피로 수정수락은 중요(헤드업), 출발/도착은 조용한 알림으로
수정(강도 낮춤)
10. 팀원 출발/도착/완료 참고
언제팀원이 링크화면에서 [출발/도착/완료] 표시상단푸시 문제점팀원 여럿이면 하루 알림 폭주(3명×3=9건) 수정‘출발’은 조용한/기본OFF, 도착·완료 유지. 종류별 ON/OFF

3. 위험도 높은 알림 TOP 5

① 부재중 자동문자 — 오발송
저장된 비고객(가족·지인)·광고 번호에도 자동으로 문자가 나갈 수 있음. 한 번 나가면 회수 불가.
→ 수정: 고객/문자이력 있는 번호에만 자동발송. 비고객·광고 제외. 카운트다운 유지.
② 협업 완료(정산) — 계좌번호 노출
완료 알림 본문에 입금 계좌번호가 들어가 잠금화면에 그대로 보임(촬영·노출 위험).
→ 수정: 본문에서 계좌번호 빼고 “정산 계좌 확인”만. 계좌는 앱 안에서. setVisibility(PRIVATE).
③ 새 문자 — 본문 노출 + 노이즈
문자 본문이 잠금화면 노출. 인증번호·광고도 “새 문자”로 울려 피로.
→ 수정: 잠금화면 본문 가림(PRIVATE) + 인증/광고 발신 제외.
④ 접수서 / D-1 — 주소·금액 노출
고객 주소·견적 금액이 잠금화면에 보임.
→ 수정: setVisibility(PRIVATE) — 잠금화면엔 제목만, 상세는 열어야.
⑤ 위치 기반(5km/3km) — 오탐 + 자동전송
과거 고객 동네를 지날 때 잘못 울리고, 3km는 주인에게 자동 전송됨. 배터리도 소모.
→ 수정: ‘오늘 예약된 현장’에만. 기본 OFF로 출시 후 검증.

4. MVP 오픈 전 반드시 고칠 것

A. 오픈 전 필수 수정 (개인정보·오발송)

  • ☐ 잠금화면 민감정보 가리기 setVisibility(PRIVATE) — 새 문자 / 접수서 / 협업 완료(계좌) / D-1(주소)
  • ☐ 협업 완료 알림에서 계좌번호 빼기 (본문 → 앱 안에서 확인)
  • ☐ 부재중 자동문자: 비고객·광고 번호 자동발송 차단
  • ☐ 새 문자: 인증번호(OTP)·광고 발신 제외
  • ☐ 발신 통화: 통화 후 카드/“캐치” = 고객·이력 있을 때만
  • ☐ 위치 5km/3km: 기본 OFF (또는 오늘 예약 현장만)

B. 오픈 후 개선 가능

  • ☐ 묶음: 잔금·D-1·팀원 진행을 한 알림으로
  • ☐ 종류별 ON/OFF (팀원 출발, 마감 브리핑 등)
  • ☐ 강도 조정: 협업/팀원 ‘출발·도착’ → 조용한 알림
  • ☐ “RING-GO 캐치!” 문구 → “방금 통화 · 후속 문자 보낼까요?”
  • ☐ 마감 브리핑 시간 설정

C. 나중에 넣어도 됨

  • ☐ 방해금지 시간대(밤엔 소리 없이)
  • ☐ 위치 geofence 정교화(반경·정확도)
  • ☐ 알림별 사용 통계로 자동 강도 조정
