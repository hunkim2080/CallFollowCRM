4. 예외 / 실패 케이스 점검

상황화면 위 표시 권한 OFF 현재통화 후 카드 못 띄움 → 상단 푸시(“RING-GO 캐치!”)로 대체. 조용히 처리. 위험낮음(폴백 있음). 단 사용자는 왜 카드가 안 뜨는지 모름. 권장권한 안내에서 “이 권한 꺼지면 통화 후 카드 대신 알림으로만 떠요” 명시. 수정필요2
상황SMS 발신 권한 없음 현재SmsSender.sendDirect=false → 자동발송 실패 기록 + 실패 알림. 위험자동문자가 ‘보냈다고 착각’ 위험은 막힘. 다만 사장님이 실패를 놓칠 수 있음. 권장실패 시 “문자 권한이 없어 못 보냈어요 — 채팅에서 직접 보내기” 명확 안내. 수정필요2
상황통화기록 권한 없음 현재번호 못 가져옴 → “(번호없음)”으로 기록, 카드/요약 매칭 불가. 위험핵심 기능(통화 후 카드/요약) 무력화. 권장권한 꺼져 있으면 홈에 상시 배너 “통화 자동 인식 꺼짐 — 켜기”. 수정필요1
상황알림 권한 없음 현재모든 notify 조용히 무시(앱 안 죽음). 위험새 문자·협업 요청 등 다 놓침 — 앱 가치 0에 수렴. 권장앱 시작 시 권한 없으면 강한 안내(설정 바로가기). 수정필요1
상황위치 권한 없음 / 배터리 최적화 현재geofence 등록 안 함(조용히), 수동 도착 버튼 폴백. OEM 자동시작 막히면 통화 receiver 호출 누락 가능(주석만). 위험위치 알림 안 옴(허용 가능) / 통화 감지 누락(심각). 권장위치=기본 OFF로 출시. 배터리 최적화 제외 안내 화면 추가. 수정필요1
상황인터넷 없음 현재추천/요약/접수폴링/협업 = getOrNull로 조용히 skip. 다듬기만 토스트. 위험사용자는 “왜 추천이 안 떠?” 모름(무반응). 권장추천영역/요약카드에 “연결 안 됨 · 다시 시도” 상태 표시. 수정필요2

6. 사용자 여정별 점검

시나리오 1. 신규 고객 전화 → 상담 → 문자 → 접수서 → 예약
정상 흐름전화 종료 → 통화 후 카드(요약+초안) → 문자 발송 → 접수서 링크 → 고객 작성 → 일정 자동 반영 끊길 지점요약 30초 내 못 옴(에이닷 미연결) / 접수서 서버 실패 / 고객이 링크 안 엶 헷갈릴 지점요약 로딩 의미(개선됨) · 접수서 발송이 자동인지 수동인지 자동화 위험없음(다 확인형) 확인 필요문자 발송·접수서 발송은 사장님 탭(유지) 개선에이닷 미연결 시 “요약 쓰려면 폴더 연결” 안내, 접수서 미열람 리마인드
시나리오 2. 문자 문의 → AI 답변 → 일정 제안 → 접수서
정상 흐름문자 수신(즉시 알림) → 채팅 진입 → 추천답변 → 일정 제안 → 접수서 끊길 지점추천 생성 ~20초 / 오프라인이면 무반응 / 고객 row는 채팅 진입 시 생성 헷갈릴 지점추천이 언제 준비되는지 / 인증·광고 문자도 알림 자동화 위험없음 확인 필요추천은 채워주기만(발송은 사장) 개선추천 ‘준비 중/실패’ 상태 표시, 인증·광고 알림 제외
시나리오 3. 부재중 → 자동문자 → 재연락 → 상담 정리
정상 흐름부재중 → 10초 카운트 → 자동문자 → 고객 재연락 → 통화 후 카드 끊길 지점발신권한 없음 / 비고객에 자동발송 / 24h 쿨다운으로 ‘안 나감’ 오해 헷갈릴 지점왜 자동문자가 안 나갔는지(쿨다운) 자동화 위험⚠️ 비고객·광고 자동발송 확인 필요카운트다운 취소 가능(유지) 개선대상=고객만, 쿨다운/스킵 사유를 카드에 표기
시나리오 4. D-1 → 당일 도착 → 완료 → 잔금 요청
정상 흐름전날 D-1 안내 → 당일 오늘시공 카드 → 완료 → 잔금 네/아니오 → 안내문자 끊길 지점위치 도착 오탐 / 잔금 자동완납 오처리 헷갈릴 지점완료=끝이 아니라 잔금 단계(개선됨) 자동화 위험잔금 ‘받음’ 자동처리, 위치 자동전송 확인 필요잔금 완납·안내문자=확인형(유지) 개선위치 오늘 현장만, 잔금 묶음 알림
시나리오 5. 팀원 현장 진행 → 사장 확인
정상 흐름배정 → 링크 → 팀원 출발/도착/완료 → 사장 알림 + 팀 현황 끊길 지점팀원 링크 만료(임시 토큰) / 인원 많으면 알림 폭주 헷갈릴 지점팀원 링크가 매번 새로 발급(영구링크 핸드오프 대기) 자동화 위험없음 확인 필요— 개선영구 링크(서버), 출발 알림 선택화·묶기
시나리오 6. 협업 공유 → 수락 → 진행 → 완료 → 정산
정상 흐름공유 요청(FCM) → 수락 → 진행 → 완료(계좌) → 입금 → 해제 끊길 지점FCM 누락(폴링 안전망 있음) / 계좌 노출 / 3km 자동전송 오탐 헷갈릴 지점계좌 어디서 보는지(통합됨) · 거절/완료 후 카드 잔존(수정됨) 자동화 위험⚠️ 3km 자동 도착 전송, 계좌 알림 노출 확인 필요입금완료 표시=수동(유지) 개선계좌 알림 본문 제거, 3km 오늘 현장만
시나리오 7. 권한 OFF / 인터넷 없음
정상 흐름권한 허용 → 정상. 미허용 → 대부분 조용히 폴백 끊길 지점통화기록·알림 권한 없으면 핵심 무력화. 오프라인 시 추천/요약 무반응 헷갈릴 지점왜 아무것도 안 뜨는지 사용자가 모름 자동화 위험— 확인 필요— 개선권한/연결 상태 상시 배너, 끄면 어떤 기능이 죽는지 명시

7. 위험도 TOP 10

① 부재중 자동문자 오발송
왜 위험자동으로 문자가 나감(회수 불가) 발생 상황가족·자재상·광고 번호 부재중 시 현재 방어스팸 앞자리 차단 + 24h 쿨다운 부족저장된 비고객·일반 광고는 못 거름 수정고객/문자이력 번호에만 자동발송 우선순위1
② 협업 완료 알림에 계좌번호 노출
왜 위험계좌번호가 잠금화면/알림에 그대로 발생 상황협업 완료 시마다 현재 방어없음(본문에 계좌 포함) 수정본문서 계좌 제거+앱에서, setVisibility(PRIVATE) 우선순위1
③ 알림 본문 잠금화면 노출(전반)
왜 위험문자내용·주소·금액이 잠금화면에 보임 발생 상황새 문자·접수서·D-1 등 현재 방어없음(setVisibility 미설정) 수정민감 알림 PRIVATE — 잠금화면엔 제목만 우선순위1
④ 위치(5km/3km) 오탐 + 자동전송
왜 위험엉뚱한 곳에서 울리고 협업 3km는 자동 전송 발생 상황과거 고객 동네 통과, GPS 부정확 현재 방어오늘~+7일 현장만(5km), 토글 부족‘오늘’ 한정 아님, 3km는 자동 발사 수정오늘 예약 현장만 + 기본 OFF 우선순위1
⑤ 발신/비고객 통화에 카드·“캐치”
왜 위험전화할 때마다 떠 피로 → 알림 끔 발생 상황자재상·가족에게 거는 전화 현재 방어5초 문턱만 수정발신은 고객/이력 있을 때만 우선순위1
⑥ 팀원/협업 번호가 고객으로 생성
왜 위험고객목록 오염 + 자동문자 대상 오인 발생 상황팀원·협업 사장과 문자/통화 현재 방어없음(번호 upsert) 수정팀원/협업 번호 태깅 → 고객·자동문자 제외 우선순위1
⑦ 통화기록·알림 권한 실패 시 핵심 무력화
왜 위험통화 인식·알림이 앱의 본체 발생 상황권한 거부, OEM 자동시작 차단 현재 방어조용한 폴백(주석만) 수정상시 배너 + 배터리 최적화 제외 안내 우선순위1
⑧ 새 문자 인증/광고 노이즈
왜 위험관심 없는 알림 → 피로/무시 발생 상황OTP·광고 수신 현재 방어스팸 앞자리만 수정인증·웹발신·광고 발신 제외 우선순위2
⑨ 잔금·D-1·팀원 알림 개별 폭주
왜 위험같은 시간 여러 알림 → 피로 발생 상황고객/팀원 다수 현재 방어고객별 1회(묶음 없음) 수정하나로 묶기 우선순위2
⑩ 오프라인 시 무반응(추천/요약)
왜 위험고장으로 오해 → 불신 발생 상황인터넷 약함/서버 다운 현재 방어조용히 skip 수정‘연결 안 됨·다시 시도’ 상태 표시 우선순위2

8. MVP 오픈 전 수정 우선순위

A. 오픈 전 반드시 수정 (신뢰 직결)

  • ☐ 민감 알림 setVisibility(PRIVATE) — 새 문자·접수서·협업완료·D-1 (잠금화면 본문/주소/금액/계좌 가림)
  • ☐ 협업 완료 알림에서 계좌번호 본문 제거 (앱 안에서 확인)
  • ☐ 부재중 자동문자 = 고객/이력 번호만 (비고객·광고 자동발송 차단)
  • ☐ 발신/비고객 통화에 카드·“캐치” 안 띄움
  • ☐ 위치 5km/3km = 오늘 예약 현장만 + 기본 OFF
  • ☐ 팀원/협업 번호 태깅 → 고객 자동생성·자동문자 제외
  • ☐ 권한 실패 상시 안내(통화기록·알림) + 배터리 최적화 제외 안내

B. 오픈 후 빠르게 개선

  • ☐ 알림 묶기(잔금·D-1·팀원)
  • ☐ 알림 종류별 ON/OFF (설정)
  • ☐ 새 문자 인증·광고 제외
  • ☐ 오프라인/실패 상태 표시(추천·요약)
  • ☐ “RING-GO 캐치!” 문구 → “방금 통화 · 후속 문자 보낼까요?”
  • ☐ 협업/팀원 ‘출발·도착’ → 조용한 알림
  • ☐ 고객 온도(leadHeat) 제거 결정 확정/정리

C. 후순위 / 나중 기능

  • ☐ 방해금지 시간대(밤엔 소리 없이)
  • ☐ 위치 geofence 정교화(반경·정확도·배터리)
  • ☐ 마감 브리핑 시간 설정
  • ☐ 추천 학습 루프(SuggestionEvent 활용)

9. 최종 판단

가장 강한 장점전화·문자 → 상담(요약·추천) → 문자/접수서 → 일정 → 계약금/잔금 → 정산까지 한 흐름으로 연결. 에이닷 통화 자동 요약, 협업의 고객정보 벽은 잘 설계됨. 가장 큰 약점① 알림 개인정보 잠금화면 노출(계좌·문자·주소) ② 자동발송·위치 자동전송 오작동 리스크 ③ 권한·OEM 실패 시 핵심 기능 취약 + 안내 부족 ④ 고객 생성 경로 분산 + 팀원/협업 번호 오염. 반드시 살릴 흐름신규 전화→통화후카드→문자/접수서 · 문자→AI답변→일정 · 접수서→일정→계약금/잔금 · D-1/완료/잔금 · 협업 요청→진행→정산 줄이거나 숨길 것위치 5km/3km(기본 OFF) · 팀원 ‘출발’ · “RING-GO 캐치!” 백업 · 고객 온도(미사용이면) 자동화 금지잔금/계약금 ‘받음’ 처리(확인 필수) · 부재중 자동문자(조건부) · 3km 자동 전송(오늘 현장만) 더 자동화 OK접수서 데이터 반영 · 통화 요약 · 알림 중복 억제(onlyAlertOnce) · 카테고리 자동분류 제품 구조 점수기능 폭/연결성: 상 · MVP 견고성(개인정보·자동화·권한): 중하 → 위 A 항목만 처리하면 오픈 가능 수준. 오픈 전 최종 권고“기능 추가 말고” A(7개) 안전·개인정보 수정에 집중. 위치/팀원출발/캐치는 기본 OFF로 줄여 출시 → 실사용 데이터로 B 개선.
